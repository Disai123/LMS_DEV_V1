Design System

The Multi-Agent Assistant utilizes a refined design system to maintain visual consistency across all agentic touchpoints. We utilize a "Dark Ethereal" palette with vibrant accent colors for different worker states.

Color Palette

Supervisor: #6366F1 (Indigo)
Search Worker: #F59E0B (Amber)
Cart Worker: #10B981 (Emerald)
Support Worker: #EF4444 (Red)

Typography

  • Main Font: Inter (Sans-serif)
  • System Font: SF Pro, Apple-System
  • Headings: 700+ Weight, -0.02em Tracking
  • Body: 400-500 Weight, 1.6 Line Height
