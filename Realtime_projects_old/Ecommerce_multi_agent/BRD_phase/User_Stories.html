User Stories

User stories define the practical value and interaction expectations of the Multi-Agent Assistant. They are written from the perspective of both the customer and the store administrator.

Customer US-01

"As a shopper, I want to find products using natural language descriptions."

The assistant should handle complex queries like "Show me red sneakers for running under $100" by delegating to the search worker and presenting filtered results directly in the chat.

Customer US-02

"As a shopper, I want the assistant to manage my cart autonomously."

The shopper should be able to say "Add that red sneaker to my cart" and the assistant will execute the corresponding tool action and provide a confirmation of the update.

Admin US-03

"As an admin, I want to see detailed reasoning logs for agent actions."

Administrators need a way to monitor agent decision-making to ensure compliance with policy and improve the system's reasoning accuracy over time.
