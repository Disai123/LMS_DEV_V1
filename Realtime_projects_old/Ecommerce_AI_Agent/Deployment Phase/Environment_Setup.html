Environment Variables

Database Configuration
DATABASE_URL=postgresql://user:pass@host:5432/dbname?sslmode=require
DB_POOL_SIZE=20
DB_TIMEOUT=30000
API Configuration
API_BASE_URL=https://api.example.com
JWT_SECRET=your-secret-key
JWT_EXPIRES_IN=7d
RATE_LIMIT=1000
AI Integration
OPENAI_API_KEY=sk-your-openai-api-key
OPENAI_MODEL=gpt-4
OPENAI_MAX_TOKENS=2000
OPENAI_TEMPERATURE=0.7
AI_RATE_LIMIT=100
NextAuth Configuration
NEXTAUTH_URL=https://your-app.vercel.app
NEXTAUTH_SECRET=your-nextauth-secret-key

Vercel Environment Setup

Steps to Configure Environment Variables in Vercel
  1. Go to your Vercel project dashboard
  2. Navigate to Settings → Environment Variables
  3. Add all required variables for Production, Preview, and Development
  4. Ensure DATABASE_URL includes ?sslmode=require
  5. Set NEXTAUTH_URL to your production domain
  6. Generate strong secrets for JWT_SECRET and NEXTAUTH_SECRET
  7. Add your OpenAI API key securely
  8. Redeploy the application after adding variables
