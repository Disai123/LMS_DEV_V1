Testing & QA

Testing a single AI agent requires both traditional API testing and specialized agentic evaluation to verify the tool execution loop behaves correctly across diverse user inputs.

API Route Tests

Focuses on JWT authentication, conversation creation, and tool execution. Uses Jest to mock OpenAI responses and verify tool dispatch logic.

npx jest tests/api/askunicart.test.ts

Frontend Verification

Ensures the chat component renders messages, handles loading states, and submits correctly. Uses Vitest for unit and Playwright for E2E.

npm run test:e2e

Agentic Evaluation

Beyond unit tests, we run specialized evals to verify the agent selects the correct tool, passes valid parameters, and produces helpful natural language responses without hallucinating product data.

  • • Tool Selection Accuracy: Does the agent pick the right tool for each query?
  • • Parameter Validation: Are product IDs and quantities passed correctly?
  • • Policy Compliance: Does the agent refuse unauthorized cart actions?
