Backend Development

The backend is a Next.js API Route at app/api/askunicart/route.ts. It handles JWT authentication, conversation history, OpenAI integration, and tool execution in a single synchronous reasoning loop.

API Route Structure

The core logic lives in a single POST handler. It authenticates the user, loads the last 20 messages for context, calls OpenAI with tools, executes any requested tools, then saves the result and returns the response.

POST Handler Flow 
export async function POST(req: NextRequest) {

}
