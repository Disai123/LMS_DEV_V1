Design System & Visual Language

For the Smart MCP Trip Planner, we've developed a "Discovery-First" design system. The goal is to balance utility (complex travel data) with inspiration (beautiful destination imagery) using a refined Glassmorphism aesthetic.

Color Palette

Sky Primary (#0ea5e9)
Action buttons, active states
Deep Space (#0f172a)
Main backgrounds, typography
Sunset Accent (#f43f5e)
Highlights, alerts, heatmaps

Typography

Used for headings and hero text
