Discovery Interface Design

The Discovery Dashboard is the core of the Trip Planner. It integrates an interactive map with real-time MCP data feeds to create a unified search and discovery experience.

Interface Components

Interactive Map Canvas

Leverages Leaflet.js with custom tiles. Features clustering for POIs (Points of Interest) and real-time weather overlays.

MCP Tool Sidebar

A slide-out panel that displays tool outputs (Weather forecasts, OSM details, Travel history) in digestible cards.

Context Omnibox

A floating search bar that handles natural language queries like "Find a sunny beach near Barcelona".

Interaction Pattern: Clicking a map marker triggers the OSM MCP tool, which populates the sidebar with location metadata, nearby photos, and wiki summaries.
Visual Feedback: Loading states for LLM reasoning are represented by a pulsing orbit animation around the omnibox.
