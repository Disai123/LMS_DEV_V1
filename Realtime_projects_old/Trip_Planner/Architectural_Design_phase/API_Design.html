API Design & Resource Definitions

The Trip Planner API acts as the secure gateway between the frontend discovery dashboard and the underlying agentic logic. We utilize FastAPI for its native support for asynchronous streaming.

POST /api/chat/stream SSE

The primary endpoint for natural language discovery. Supports token-by-token streaming of agent reasoning.

Payload: { "query": "Find me a hotel in Paris", "thread_id": "uuid" }
GET /api/tools/manifest REST

Exposes available MCP tools to the frontend, including their schema and UI rendering hints.

Security Note:

All API endpoints are protected by Pydantic validation and a zero-trust proxy layer that sanitizes tool inputs before they reach the MCP servers.
