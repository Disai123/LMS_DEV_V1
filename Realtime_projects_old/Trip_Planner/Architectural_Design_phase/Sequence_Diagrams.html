Interactive Sequence Flow

Understanding the data flow is critical when building agentic systems. This sequence demonstrates how a single user click triggers a multi-step background orchestration.

# User clicks "Taj Mahal" on Map
Frontend -> FastAPI: GET /agent/details?place="Taj Mahal"
# LangGraph Starts Phase
PlannerNode: Decides tools needed [Weather, Distance]
ToolNode -> OSM_MCP: get_weather("Taj Mahal")
OSM_MCP --(22°C Cloud)--> ToolNode
ToolNode -> Travel_MCP: search_transports("Agra")
Travel_MCP --(Agra Cantt 5km)--> ToolNode
SynthesisNode: "It's 22°C. Nearest station is Agra Cantt..."
FastAPI -> Frontend: { "weather": "Cloudy", "insights": "..." }

Key Takeaways

  • Async Handling: Each tool call is independent but orchestrated sequentially or in parallel by the graph.
  • State Persistence: The "Source" location remains in the graph state, allowing the LLM to calculate "Travel: 5h 20m from [Source]" without re-querying.
  • Decoupling: The UI only waits for the final JSON, while the agent handles complex API logic.
