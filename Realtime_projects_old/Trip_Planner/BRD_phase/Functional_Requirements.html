Functional Requirements

The functional requirements define the core capabilities that the Smart MCP Trip Planner must provide to ensure a seamless and value-driven user experience.

01

Source Anchor & Context Persistence

The system must capture and persist the user's "Source City" at the beginning of the flow. This context is used for all subsequent travel duration, distance, and flight calculations.

02

Interactive Destination Mapping

Integration with OpenStreetMap (via MCP) to display destination cities with interactive markers for famous places. Users can click markers to trigger detailed insights.

03

Real-time Weather & Transport Insights

Fetching live weather data for places of interest. AI-powered qualitative data generation for best visiting times and distance to local transport hubs (Airport, Railway, Bus).

04

Unified Booking Redirection

Consolidated view for flights and hotel inventories (via MCP/Local DB) with a "One-Click" redirection to external booking platforms like MakeMyTrip.
