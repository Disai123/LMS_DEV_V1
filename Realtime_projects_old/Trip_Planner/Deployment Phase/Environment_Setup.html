Environment Setup & Secrets

A secure environment configuration is critical for the Trip Planner, as it requires multiple API keys (Gemini, OSM, Weather) that must never be exposed to the client-side code.

Production .env Template

# Core AI Configuration
GOOGLE_API_KEY=your_gemini_key_here
LANGCHAIN_TRACING_V2=true
LANGCHAIN_PROJECT="Trip-Planner-Prod"

# MCP Tool Servers
WEATHER_SERVICE_URL=http://weather-mcp:5000
OSM_API_KEY=your_osm_key_here

# Backend Security
SECRET_KEY=highly_secure_long_random_string
ALLOWED_ORIGINS=https://your-trip-planner.com

# Database
DATABASE_URL=postgresql://user:pass@host:5432/travel_db
Secret Management

In production, use tools like AWS Secrets Manager or Google Secret Manager to inject these variables at runtime, rather than bundling them in Docker images.

Backend Proxying

Our FastAPI backend acts as a proxy—the Frontend never talks to the AI or tool APIs directly, preventing key leakage and CORS issues.
