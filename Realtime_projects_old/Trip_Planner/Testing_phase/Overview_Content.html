Testing & Quality Assurance

QA Strategy

Testing an agentic system requires a multi-layered approach. We must verify not only the UI components but also the reliability of the LangGraph state transitions and the accuracy of MCP tool calls.

Agentic Reasoning Tests

Verifying that the LLM correctly identifies which tools to call. For example, ensuring that "Check weather in Coorg" triggers only the Weather MCP tool and not the Flight tool.

UI/UX Interaction Testing

Validating map markers, hover effects, and the smooth expansion of the glassmorphism sidebar using tools like Playwright or manual sanity checks.

API & Tool Connection Testing

Writing integration tests to ensure the FastAPI proxy correctly handles large JSON payloads from Nominatim and OpenMeteo without timeouts.
