Backend: Agentic Orchestration

The backend is a FastAPI application that serves as the gateway to the LangGraph Agent. It processes user messages and invokes the intelligent graph nodes.

main.py FastAPI
@app.post("/api/agent/invoke", response_model=AgentResponse)
async def invoke_agent(req: AgentRequest):
# Construct Inputs for LangGraph
inputs = {
    "messages": [HumanMessage(content=req.message)],
    "source": req.source,
    "destination": req.destination,
    "current_place": req.place_context
}
try:
    # Run the Agentic Graph
    result = await agent_app.ainvoke(inputs)
    last_msg = result["messages"][-1]
    return AgentResponse(response=last_msg.content)

Key Implementation Details

  • State Injection: We pass `source` and `destination` directly into the graph state to ensure context persistence across turns.
  • Async Await: LangGraph invokes are asynchronous, allowing the FastAPI server to handle multiple planning requests simultaneously.
  • MCP Integration: The `agent_app` contains nodes that internally use the MCP SDK to connect to tool servers.
