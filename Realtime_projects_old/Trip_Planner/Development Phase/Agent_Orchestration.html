Agent Orchestration with LangGraph

The core logic of the Trip Planner is built on LangGraph. This allows us to define cyclic graphs where the agent can reason, call tools, and re-evaluate its plan based on tool outputs.

Orchestration Implementation

from langgraph.graph import StateGraph, END

# Define the state for our agent
class AgentState(TypedDict):
    messages: Annotated[Sequence[BaseMessage], operator.add]
    itinerary_draft: dict
    current_weather: dict

# Initialize the graph
workflow = StateGraph(AgentState)

# Add reasoning and tool nodes
workflow.add_node("agent", call_model)
workflow.add_node("tools", tool_node)

# Define edges and cycles
workflow.set_entry_point("agent")
workflow.add_conditional_edges(
    "agent",
    should_continue,
    {
        "continue": "tools",
        "end": END
    }
)
workflow.add_edge("tools", "agent")

# Compile the graph
app = workflow.compile(checkpointer=memory)
State Management

The AgentState keeps track of the evolving itinerary. Any tool results (like weather) are automatically merged into the shared state.

Conditional Routing

The should_continue function analyzes the LLM's last message. If a tool call is requested, it routes to tools; otherwise, it ends the turn.
