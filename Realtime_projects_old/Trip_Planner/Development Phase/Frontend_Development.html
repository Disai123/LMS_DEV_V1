Frontend: Interactive React Map

The frontend is a React application using Leaflet for mapping and Framer Motion for the premium glassmorphism animations.

App.jsx React
const handleMarkerClick = async (place) => {
setSelectedPlace(place); // Invoke Agent with Context
const res = await agentApi.invoke(`Analyze ${place.name}`, {
    source: localStorage.getItem("source"),
    destination: place.name,
    place_context: place.name
});
setDetails(res.response);
};

</MapContainer>

Frontend Innovations

  • 📍 Event Handlers: Markers capture interactions to trigger backend agent calls with specific geographical context.
  • 🎭 AnimatePresence: Used to create high-end sidebar transitions when a place detail is loading or selected.
  • 🧊 Glass Container: Tailwind CSS utilities combined with custom glass-panel styles for consistent branding.
