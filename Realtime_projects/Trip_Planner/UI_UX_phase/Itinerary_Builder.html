Itinerary & Route Planning UX

Moving from discovery to planning, the Itinerary Builder provides a structured way for users to interact with AI-generated suggestions and refine their travel sequences.

UX Principles

01
Drag-and-Drop Optimization

Users can reorder locations on the fly, triggering automatic distance recalculations via OSM.

02
AI Suggestion Chips

LLM provides context-aware chips like "Add lunch break nearby" or "Optimized for Sunset".

State Transitions

  • • Idle: Showing current location and local weather.
  • • Searching: Map zooms out, showing clusters of possibilities.
  • • Planning: Sidebar expands to multi-day view, route lines appear on map.
  • • Exporting: Generating PDF/Markdown summary of the trip.
User Goal Focus:

The UX ensures that the user never feels lost in the "Agentic" loop. Clear status bars explain what the AI is currently fetching (e.g., "Fetching local cafes from OpenStreetMap...").
