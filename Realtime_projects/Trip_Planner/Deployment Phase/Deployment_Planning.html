Deployment Strategy & Cloud Planning

Deploying a multi-service agentic platform requires a robust plan for containerization, secret management, and auto-scaling to handle the unpredictable loads of LLM reasoning.

Target Infrastructure

1
Containerization (Docker)

We bundle the FastAPI backend, LangGraph orchestrator, and individual MCP servers into light-weight Docker images.

2
Serverless Hosting (Cloud Run)

Deploying to platforms like Google Cloud Run ensures we only pay for the execution time of our agent's reasoning turns.

3
Static Delivery (CDN)

The React discovery dashboard is optimized and served via a global CDN for low-latency map tile loading.

Deployment Tip:

Always use a reverse proxy (like Nginx or Cloud Identity-Aware Proxy) to handle SSL termination and protect your MCP herramienta endpoints from unauthorized access.
