System Architecture & Agentic Flow

The Smart MCP Trip Planner follows a decoupled, agentic architecture. The core reasoning is handled by a LangGraph orchestrator that interacts with multiple specialized MCP tool servers.

High-Level Infrastructure

Frontend (React + Leaflet)
↕
Agent Proxy (FastAPI)
↕
Weather MCP
OSM MCP
Travel DB MCP
Agent Reasoning Node

The brain of the system. It receives natural language requests, evaluates current state, and decides which MCP tool to call based on tool manifests.

MCP Tool Interface

Standardized Model Context Protocol wrappers ensure that tools from different developers can be swapped without rewriting agent logic.

State Persistence

Utilizes LangGraph Checkpointers to save conversation history and itinerary state, allowing for resumeable long-term travel planning.
