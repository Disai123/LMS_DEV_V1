System Overview & Orchestration

Architectural Deep Dive

The Smart MCP Trip Planner uses an Agentic Workflow powered by LangGraph. Instead of a rigid procedural script, the system uses an LLM (Gemini) as a "Reasoning Engine" to decide which MCP tools to invoke based on user intent.

Orchestration Layer

LangGraph manages the conversation state and intelligently routes requests to the Planner, Tools, or Final Generator nodes.

MCP Infrastructure

Decoupled servers for Maps (OSM), Weather (OpenMeteo), and Travel (SQLite) communicate via standardized MCP protocol.

Technology Blueprint

FRONTEND React 18 + Leaflet
BACKEND FastAPI + LangGraph
MODEL Google Gemini Pro
STANDARDS Model Context Protocol
