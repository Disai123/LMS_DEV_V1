Map Integration & Reactive Display

The frontend uses React Leaflet to render the discovery dashboard. The map is deeply integrated with the agentic state, updating reactively as the AI finds new locations.

React Leaflet Implementation

import { MapContainer, TileLayer, Marker, Popup } from 'react-leaflet';

const DiscoveryMap = ({ locations }) => {
  return (
    <MapContainer center={[48.8566, 2.3522]} zoom={13} style={{ height: '500px' }}>
      <TileLayer url="https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png" />
      {locations.map(loc => (
        <Marker key={loc.id} position={[loc.lat, loc.lon]}>
          <Popup>
            <div className="font-semibold">{loc.name}</div>
            <p className="text-sm">{loc.description}</p>
          </Popup>
        </Marker>
      ))}
    </MapContainer>
  );
};
Live Tile Updates:

We use OpenStreetMap contributors' API for free, high-quality map tiles that work seamlessly with our POI discovery markers.

Viewport Sync:

When the agent performs a "Geographic Reach" tool call, the map's bounds are automatically adjusted to encompass all found locations.
