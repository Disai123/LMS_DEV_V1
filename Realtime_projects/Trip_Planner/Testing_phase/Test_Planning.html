Test Planning & Strategy

Testing an agentic system like the Trip Planner requires a multi-layered strategy that covers not just code correctness, but reasoning accuracy and tool reliability.

QA Categories

Agent Eval

Verifying that the LLM picks the right tool for the right query (e.g., "Paris" -> OSM Tool).

Mock MCP

Using mock servers to test agent recovery when a tool (like Open-Meteo) is down.

Visual Map QA

Automated tests for marker clustering and popup rendering correctness.

Test Success Criteria:
  • ✓ 95% + Trajectory accuracy for common travel queries.
  • ✓ Less than 1s latency for tool dispatch.
  • ✓ Zero secret leakage in LLM logs.
  • ✓ Responsive map tiles across mobile and desktop.
