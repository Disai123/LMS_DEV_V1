Integration Testing & E2E Flows

Integration tests verify that the entire chain works together: from the user query on the React frontend to the LangGraph reasoning and final tool execution.

Full Travel Cycle Verification

Scenario: Trip Discovery in Paris
  1. User input: "I'm in Paris, show me nearby cafes and weather."
  2. Frontend: Sends SSE request with thread_id.
  3. Backend: LangGraph identifies two tool calls needed (OSM + Weather).
  4. Orchestration: Parallels tool calls and merges results into state.
  5. Delivery: Frontend receives markers and weather card via stream.
State Persistence Checks
