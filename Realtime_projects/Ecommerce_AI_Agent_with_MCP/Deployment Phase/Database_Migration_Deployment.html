Database Migration & Deployment

Deploy and manage database schema migrations for the askunicart AI agent, ensuring data integrity and smooth transitions between environments.

Database Schema Overview

Core Models
  • • User: Authentication and user profiles
  • • Category: Product categories
  • • Product: Product catalog
  • • Order: Customer orders
  • • CartItem: Shopping cart items
  • • WishlistItem: User wishlists
AI Agent Models
  • • Conversation: AI chat sessions
  • • Message: Individual chat messages
  • • ToolCall: AI tool execution logs
  • • AgentContext: Conversation context

Prisma Migration Process

1. Generate Prisma Client
# Generate Prisma Client from schema
npx prisma generate

# This creates the Prisma Client in node_modules/.prisma/client
# Required before running migrations
2. Create Migration
# Create a new migration
npx prisma migrate dev --name init

# This will:
# - Create migration files in prisma/migrations/
# - Apply the migration to your database
# - Regenerate Prisma Client
3. Deploy Migration to Production
# Deploy migrations to production (Vercel)
npx prisma migrate deploy

# This applies pending migrations without:
# - Creating new migrations
# - Regenerating Prisma Client
# - Running seed scripts
4. Push Schema Changes (Development Only)
# Push schema changes directly (dev only)
npx prisma db push

# WARNING: Use only in development
# This does not create migration files
# Use migrate dev for production workflows

Vercel Deployment Configuration

Postinstall Script

Add to package.json to automatically generate Prisma Client on deployment: 

{
  "scripts": {
    "postinstall": "prisma generate"
  }
}
Vercel Build Configuration

Configure vercel.json for proper build settings: 

{
  "buildCommand": "npm run build",
  "framework": "nextjs",
  "functions": {
    "app/api/**/*.ts": {
      "maxDuration": 30
    }
  }
}
