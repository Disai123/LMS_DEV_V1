Tool Modules Development

Tool modules are specialized functions that the AI can call to interact with the e-commerce system. Each module handles a specific domain: product search, inventory, recommendations, and cart management.

📚 Catalog Scout (catalog.ts)

searchProducts
  • Searches products by name, description, brand, tags
  • Filters by category, price range, stock availability
  • Returns product list with images, prices, ratings
  • Uses Prisma with case-insensitive search
getProductDetails
  • Retrieves detailed product information
  • Accepts productId or productSlug
  • Includes images, specifications, reviews
  • Returns stock quantity and availability
getCategories
  • Lists all active product categories
  • Returns category hierarchy
  • Includes product counts per category

📦 Inventory Sentinel (inventory.ts)

checkStock
  • Checks stock availability for products
  • Accepts productId, productSlug, or category
  • Returns stock quantity and status
  • Handles out-of-stock scenarios

🎯 Recommendation Engine (recommendations.ts)

getRecommendations
  • Generates product recommendations
  • Can recommend by category
  • Can find similar products to a given productId
  • Returns top N recommendations (default: 5)
  • Prioritizes in-stock items

🛒 Cart Manager (cart.ts)

addToCart
  • Adds product to user's cart
  • Accepts productName (searches) or productId
  • Validates stock availability
  • Handles quantity specification
  • Returns cart summary
getCart
  • Retrieves user's current cart
  • Returns all items with quantities and prices
  • Calculates subtotal, tax, shipping, total
  • Includes product details for each item
updateCartItem
  • Updates quantity of cart item
  • Validates new quantity against stock
  • Removes item if quantity set to 0
removeFromCart
  • Removes item from cart
  • Accepts productName or productId
  • Confirms removal
