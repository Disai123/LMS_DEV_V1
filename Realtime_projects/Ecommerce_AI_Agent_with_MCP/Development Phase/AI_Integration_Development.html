AI Integration Development

The AI integration code connects the API route with OpenAI's GPT models, handles function calling, and manages conversation context. This is the core intelligence layer of the agent.

🤖 OpenAI Client Setup 

// Initialize OpenAI client
import OpenAI from 'openai'

const openai = new OpenAI({
  apiKey: process.env.OPENAI_API_KEY
})

// Model configuration
const model = process.env.OPENAI_MODEL || 'gpt-4o-mini'

💬 Chat Completion Call 

const completion = await openai.chat.completions.create({
  model: 'gpt-4o-mini',
  messages: [
    { role: 'system', content: SYSTEM_PROMPT },
    ...conversationHistory,
    { role: 'user', content: userMessage }
  ],
  tools: tools, // Array of tool definitions
  tool_choice: 'auto', // Let AI decide when to use tools
  temperature: 0.7,
  max_tokens: 1000
})

🔧 Tool Execution Flow

1. AI Requests Tool

OpenAI response includes tool_calls array with function name and parameters.

2. Execute Tool
// Map tool name to function
const toolMap = {
  'searchProducts': catalogTools.searchProducts,
  'addToCart': cartTools.addToCart,
  // ... other tools
}

const toolFunction = toolMap[toolCall.name]
const result = await toolFunction(params)
3. Return Result to AI

Tool result added to messages array, then call OpenAI again to generate final response.
