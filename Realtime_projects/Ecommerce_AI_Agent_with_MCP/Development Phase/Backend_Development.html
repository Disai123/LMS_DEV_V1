Backend Development

The backend API route (`app/api/askunicart/route.ts`) handles all AI agent requests. It manages authentication, conversation history, OpenAI integration, and tool execution.

📝 API Route Structure 

// app/api/askunicart/route.ts

export async function POST(req: NextRequest) {
  // 1. Authenticate user (JWT validation)
  // 2. Parse request body (message, conversationId)
  // 3. Load conversation history (last 20 messages)
  // 4. Call OpenAI API with context and tools
  // 5. Handle tool calls if any
  // 6. Save messages to database
  // 7. Return AI response
}

export async function GET(req: NextRequest) {
  // 1. Authenticate user
  // 2. Get conversationId from query params
  // 3. Load conversation with messages
  // 4. Return conversation data
}

🔐 Authentication Middleware

JWT Validation
const user = await withAuth(req)
// Extracts JWT token from Authorization header
// Validates token and returns user object
// Returns 401 if invalid
User ID Extraction

User ID extracted from validated JWT token. Used to isolate conversations and cart operations.

💬 Conversation Management

Create or Load Conversation
// If conversationId provided, load existing
// Otherwise, create new conversation
const conversation = conversationId
  ? await prisma.conversation.findUnique(...)
  : await prisma.conversation.create(...)
Load Message History
// Load last 20 messages for context
const messages = await prisma.message.findMany({
  where: { conversationId },
  orderBy: { createdAt: 'desc' },
  take: 20
})
Save Messages

Both user message and AI response are saved to database after successful AI call.

🔄 Error Handling

OpenAI API Errors

Try-catch blocks handle API failures, return user-friendly error messages.

Database Errors

Prisma errors caught and logged, graceful error responses returned.

Validation Errors

Input validation before processing, return 400 Bad Request for invalid inputs.
