Integration Testing

Integration tests run React to FastAPI to LangGraph to FAISS. They check POST /rag/ask, citations, no-data behavior, and existing store health.

🔌 API Integration Tests

POST /rag/ask
  • Authenticated request succeeds
  • Unauthenticated request returns 401
  • Normal manual questions return an answer and sources
  • No-data questions return found=false
  • Optional product context is accepted
  • Existing store APIs are unchanged

🤖 RAG Flow Tests

LangGraph + FAISS
  • Question embeddings search the FAISS index
  • Relevant chunks are selected
  • Weak context triggers one retrieval retry
  • Answer text is limited to retrieved content
  • Citations match document and section metadata
Error and safety tests
  • Missing index returns a clear error
  • Prompt-injection text is not treated as a command
  • User-friendly error messages are returned

🗄️ End-to-End Store Check

Existing features
  • Login still works
  • Product browsing still works
  • Cart and checkout still work
Langfuse
  • Trace shows retrieve and answer steps
  • Eval scores can be recorded
  • Secrets are not logged
