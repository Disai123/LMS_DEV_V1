Unit Testing

Unit tests cover ingest, chunking, embeddings, and FAISS retrieval in isolation. They do not test cart tools. Compare returned chunks with the expected manual section.

📄 Ingest and Chunking Tests

Document loading
  • Approved manuals load and extract text
  • Obvious noise is removed
  • Document name and product metadata are attached
Chunking
  • Chunks respect size and overlap
  • Section names are kept when present
  • Empty or tiny leftover chunks are not stored

🔎 Embeddings and FAISS Tests

Index build
  • Each chunk gets an embedding
  • FAISS index writes successfully
  • Metadata maps vector ids back to sources
Sample retrieval
  • A known pairing question returns the pairing section
  • Unrelated queries stay below the relevance threshold
  • Result limit is respected

📎 Grounding Helpers

Citation and refusal helpers
  • Source list is built from retrieved metadata
  • Empty retrieval produces a not-found result
  • Clarification is requested when the product is missing
