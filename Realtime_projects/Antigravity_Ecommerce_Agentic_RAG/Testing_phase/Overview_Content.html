Testing Overview

Project Video

This phase tests the Agentic RAG E-Commerce Assistant. The main checks are retrieval quality, citation accuracy, and hallucination refusal. Also confirm the existing store still works.

Testing Objectives

  • Check FAISS retrieval against real manuals
  • Verify citations match the used sections
  • Confirm no-data and prompt-injection cases are safe
  • Test POST /rag/ask with existing auth
  • Test the React assistant states in the browser
  • Record Langfuse eval scores where available
