✅ Test Cases

Retrieval Quality
  • Usage instruction from a user manual
  • Specification that exists in the document
  • Warranty question only when the document contains it
  • Troubleshooting and compatibility questions
  • Weak matches stay below the relevance threshold
Citation and Grounding
  • Source document name is shown
  • Section matches the used chunk
  • Answer text can be found in the retrieved content
  • No invented specs or safety guidance
Hallucination and Safety
  • No-data questions say information was not found
  • Ambiguous questions ask for clarification
  • Irrelevant and prompt-injection cases stay safe
  • Incorrect assumptions are not confirmed

🎯 Success Criteria

Grounding

Answers match retrieved approved documents or clearly say not found.

Citations

Source references are correct for every grounded answer.

Store safety

Existing login, catalog, cart, and checkout still work.
