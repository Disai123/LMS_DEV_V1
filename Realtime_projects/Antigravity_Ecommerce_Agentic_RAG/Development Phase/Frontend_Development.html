Frontend Development

The frontend is a simple assistant added to the existing ReactJS app. It posts questions to FastAPI POST /rag/ask and shows the answer, citations, a no-data message, a clarification, or an error. Do not redesign unrelated store screens.

Assistant Component

One entry point with a question box and ask action. From a product page it can pass the existing product id so retrieval uses that product's manuals.

Ask action
const response = await fetch('/rag/ask', {
    method: 'POST',
    headers: { Authorization: `Bearer ${existingToken}` },
    body: JSON.stringify({ question, product_id })
});

UI State

The assistant shows loading while FastAPI runs retrieval, then renders the answer and source references.
