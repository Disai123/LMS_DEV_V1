RAG Pipeline Modules

These modules process approved product documents. They are not cart or stock tools. The pipeline is ingest, clean, chunk, embed, index in FAISS, retrieve, then cite.

Document Ingestion

Load product manuals, user manuals, usage guides, FAQs, and warranty files. Extract text and remove obvious noise.

load_documents · extract_text · clean_text

Chunking

Split cleaned text with a chosen chunk size and overlap. Attach document name, product, and section metadata.

split_chunks · attach_metadata

Embeddings and FAISS

Convert each chunk to an embedding and store it in a FAISS index. Keep a metadata map for citations.

embed_chunks · build_faiss_index · save_metadata

Retrieval Service

Embed the question, search FAISS, apply a relevance threshold, and return chunks for the grounded answer.

retrieve
check_relevance
cite_sources
