Tool Modules Development

Tool modules are specialized functions the AI can call to interact with the e-commerce system. Each module handles a specific domain. They are registered with the OpenAI SDK so the model can decide when and how to invoke them.

📚 Catalog Scout

Handles all product discovery. Accepts natural language queries and translates them into Prisma database searches with category, price, and stock filters.

searchProducts · getProductDetails · getCategories

📦 Inventory Sentinel

Checks real-time stock availability. Accepts productId, productSlug, or category as input and returns stock quantity and status, handling out-of-stock scenarios gracefully.

checkStock · getStockStatus

🎯 Recommendation Engine

Generates product recommendations by category or similarity to a given product. Prioritizes in-stock items and returns the top N results (default: 5).

getRecommendations · getSimilarProducts

🛒 Cart Manager

Handles all cart mutations. Accepts natural language (product name) or direct productId. Validates stock before adding, calculates totals including tax and shipping.

addToCart
getCart
removeFromCart
