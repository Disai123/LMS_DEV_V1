Backend Development

The RAG backend is added to the existing FastAPI app as POST /rag/ask. It reuses current authentication, accepts an optional product context, and runs the LangGraph flow over FAISS embeddings. Existing store APIs stay unchanged.

POST /rag/ask Flow

The handler authenticates with the existing login, reads the question, runs the RAG agent, and returns a grounded answer plus safe source references.

Handler steps 
@router.post("/rag/ask")
async def rag_ask(req: RagAskRequest, user=Depends(existing_auth)):
    question = req.question
    product_id = req.product_id          # optional existing catalog context

    return {
        "answer": result.answer,
        "found": result.found,
        "sources": result.sources,       # document + section citations
    }
