FAISS Index Implementation

The knowledge layer is a FAISS index of document embeddings. We do not create a second store database for catalog data. Existing auth and product tables stay in place.

# Build embeddings and write the FAISS index
chunks = load_cleaned_chunks()
vectors = embed(chunks)
index = faiss.IndexFlatIP(dim)
index.add(vectors)
save(index, metadata) # document, product, section, chunk text

Each vector maps back to a document name and section so the answer can show citations. Re-run the script when manuals are added or updated.

Implementation Highlights

Local folder for the FAISS index and metadata.
Chunk size and overlap chosen for manuals and FAQs.
Relevance threshold so weak matches are not used.
Existing catalog is reused only for optional product context.
