User Stories

User stories describe the Agentic RAG assistant from the customer and store-operator view. Each story follows: "As a [user type], I want [goal] so that [benefit]."

📘

US-RAG-001: Ask About a Manual

As a customer, I want to ask how to use a product so that I get instructions from the approved user manual, not a guessed answer.

Example Queries:

  • "How do I pair these wireless headphones?"
  • "What does the warranty cover for the smart watch?"
  • "How do I clean the office chair fabric?"
🔗

US-RAG-002: See Citations

As a customer, I want to see the source document and section so that I can check the answer against the original manual.

Example Result:

  • Answer text grounded in retrieved chunks
  • Source: Headphones User Manual, Pairing section
🚫

US-RAG-003: Honest No-Data Reply

As a customer, I want to be told when the manuals do not contain the answer so that I do not follow invented specs or safety advice.

Example Queries:

  • "Does this charger work at 240V?" when the FAQ never states it
  • "What is the return policy for order #1042?" (out of scope)
🛒

US-RAG-004: Ask From a Product Page

As a customer, I want to open the assistant on a product page so that my question uses that product context when searching manuals.

Example Queries:

  • "How long is the battery warranty?" on the Smart Watch page
  • "What is in the box?" on the headphones page
❓

US-RAG-005: Clarify Vague Questions

As a customer, I want the assistant to ask which product I mean so that it does not retrieve the wrong manual.

Example Conversation:

User: "How do I charge it?"
Assistant: "Which product are you asking about?"
📚

US-RAG-006: Update Manuals

As a store operator, I want to add or replace an approved manual so that the FAISS index can be rebuilt and answers stay current.

Example Tasks:

  • Add a new warranty PDF
  • Re-run ingest, chunking, embeddings, and FAISS index
