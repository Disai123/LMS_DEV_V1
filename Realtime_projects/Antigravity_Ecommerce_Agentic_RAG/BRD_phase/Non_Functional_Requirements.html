Non-Functional Requirements

These quality rules apply to the Agentic RAG assistant on the existing React + FastAPI store. They cover retrieval speed, grounding, security, and observability with Langfuse.

⚡ Performance Requirements

ID Requirement Target Priority
NFR-PF-001 Grounded answer time Useful reply from POST /rag/ask in a few seconds High
NFR-PF-002 FAISS retrieval time Fast similarity search over document embeddings High
NFR-PF-003 Index rebuild Re-run ingest and embeddings when manuals change Medium
NFR-PF-004 Chat UI load Assistant entry point stays light on the existing store High

🔒 Security Requirements

ID Requirement Description Priority
NFR-SE-001 Reuse existing auth POST /rag/ask uses the store's current login High
NFR-SE-002 Secret handling API keys and tokens stay in environment variables High
NFR-SE-003 Untrusted input User questions and retrieved document text are untrusted High
NFR-SE-004 Prompt-injection defense Ignore hidden instructions in questions or manuals High
NFR-SE-005 Grounding rule Never invent specs, warranty, or safety guidance High

📊 Quality and Observability

ID Requirement Target Priority
NFR-QL-001 Retrieval relevance Returned chunks match the asked manual topic High
NFR-QL-002 Citation accuracy Source references match the used chunks High
NFR-QL-003 Hallucination refusal Say “not found” when documents do not support the answer High
NFR-QL-004 Langfuse evals Trace retrieval, retries, grounding, and source scores High

✨ Usability Requirements

ID Requirement Description Priority
NFR-US-001 Simple entry point One assistant UI inside the existing store High
NFR-US-002 Visible sources Show document and section references with the answer High
NFR-US-003 Clear empty and error states Loading, no-data, clarification, and error messages High
