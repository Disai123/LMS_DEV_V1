Project Overview

Project Video

This phase writes the Business Requirements Document for the Agentic RAG E-Commerce Assistant. The feature is added to an existing store. It answers product questions from approved manuals, usage guides, FAQs, and warranty documents. It does not rebuild the store and it does not query orders or cart data as its main job.

Phase Objectives

  • Define in-scope questions about manuals, FAQs, warranty, and usage
  • List approved document types and where they are stored
  • Document the ingest, chunk, embed, retrieve, and cite flow
  • State that answers must be grounded and include source references
  • Mark out-of-scope work: rebuilding the store or inventing specs
  • Set success criteria for retrieval quality and hallucination refusal

What is the Agentic RAG assistant?

It is a product-knowledge assistant inside the existing e-commerce app. Users ask natural-language questions. FastAPI POST /rag/ask runs an agentic RAG flow over a FAISS index of embeddings. Answers come only from retrieved approved documents and include citations.
