System Architecture

The Agentic RAG assistant sits inside the existing e-commerce app. React sends questions to FastAPI. LangGraph runs query understanding, FAISS retrieval of embeddings, a relevance check, and a grounded answer with citations. We do not add a second store database for catalog data.

🔄 Request Flow

1
User asks a question
React chat UI posts to FastAPI POST /rag/ask
↓
2
Reuse existing auth
Optional product context is passed from a product page
↓
3
Understand and plan search
LangGraph decides whether to search and may rewrite the query
↓
4
FAISS retrieval
Embed the question and search the document chunk index
↓
5
Relevance check
If context is weak, retrieve again with a better query
↓
6
Grounded answer with citations
Answer only from retrieved manuals. If not found, say so.

🧩 Component Responsibilities

React UI
  • Question box and ask action
  • Loading, error, and no-data states
  • Show citations / source references
FastAPI /rag/ask
  • Reuse existing authentication
  • Accept optional product context
  • Return answer plus safe sources
LangGraph agent
  • Query rewrite
  • Context check and retry
  • Grounded answer step
FAISS index
  • Store document embeddings
  • Return matching chunks
  • Keep document and section metadata
