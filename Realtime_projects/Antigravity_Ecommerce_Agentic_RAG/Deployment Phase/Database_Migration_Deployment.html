FAISS Index Deployment

This feature ships a FAISS index of document embeddings, not a new store schema. Reuse the existing catalog. Rebuild the index when approved manuals change.

What Gets Deployed

Existing store
  • • Current users and login
  • • Current product catalog
  • • Current cart and checkout
  • • Do not create a second catalog database
RAG files
  • • Approved manuals and FAQs
  • • Chunk metadata
  • • Embeddings in a FAISS index
  • • Rebuild script for document updates

Index Rebuild Process

1. Add or replace manuals
# Put approved PDFs or text files in the documents folder
# Keep only product manuals, FAQs, usage guides, warranty text
2. Ingest, chunk, embed
# Run the project index script
# Writes FAISS index + metadata (document, product, section)
3. Deploy the new files
# Copy index + metadata onto the FastAPI service
# Restart so POST /rag/ask loads the new embeddings
# Ask a known manual question and check citations

Index Checklist

Before rebuild
✓
Only approved documents are included
✓
Keep a copy of the previous index
After rebuild
✓
Sample query retrieves the new section
✓
Citations still show document and section
