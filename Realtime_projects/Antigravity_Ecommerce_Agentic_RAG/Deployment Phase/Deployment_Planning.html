Agentic RAG Deployment Planning

Deploy the assistant on the existing React + FastAPI app. Include the FAISS index, embeddings, LangGraph flow, and Langfuse. The reference live app is on Render.

Deployment Possibilities

Local
💻 Existing app locally
Purpose: Build and test RAG on the current store
Needs: React, FastAPI, FAISS files, embedding access
Do not: Rebuild the store or add a second catalog database
Cloud
▲ Render (used for the live demo)
Services: React frontend and FastAPI backend
Index: FAISS files deployed with the backend
Observability: Langfuse traces and evals
Live: https://agentic-rag-fastapi-frontend.onrender.com
