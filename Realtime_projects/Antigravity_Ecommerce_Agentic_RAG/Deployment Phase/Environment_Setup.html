Environment Setup

Configure local and Render environments for the existing React frontend, FastAPI backend, FAISS index, embeddings, LangGraph, and Langfuse.

Environment Configuration

Local Development
Configuration
  • • Existing React frontend
  • • Existing FastAPI backend
  • • Local FAISS index folder
  • • Sample approved manuals
Access
  • • Reuse existing login
  • • Local embedding model or key
  • • Optional local Langfuse
Render Production
Configuration
  • • React service on Render
  • • FastAPI service on Render
  • • FAISS index deployed with the backend
  • • Live demo URL for students
Access
  • • Existing store users
  • • Restricted admin access
  • • Langfuse project for traces

Environment Variables

Frontend (React)
VITE_API_BASE_URL=https://your-fastapi-service.onrender.com
FastAPI + RAG
FAISS_INDEX_PATH=./data/faiss.index
FAISS_METADATA_PATH=./data/faiss_metadata.json
EMBEDDING_MODEL=your-embedding-model
EXISTING_AUTH_SECRET=reuse-store-secret
Langfuse
LANGFUSE_PUBLIC_KEY=your-public-key
LANGFUSE_SECRET_KEY=your-secret-key
LANGFUSE_HOST=https://cloud.langfuse.com

Render Environment Setup

Steps on Render
  1. Create a FastAPI web service and a React static or web service
  2. Point the React app at the FastAPI URL
  3. Add embedding, auth, and Langfuse keys as secret env vars
  4. Include the FAISS index files in the backend deploy or persistent disk
  5. Confirm POST /rag/ask returns citations on the live URL
  6. Do not put keys in the React client
