Navigation Flow

The chat interface integrates seamlessly with the main e-commerce application. This section outlines how users navigate between the chat and other parts of the application.

🗺️ Chat Integration Points

Global Access

Chat button available on all pages (product pages, cart, checkout, etc.)

Product Page

Users can ask about product details, stock, or add to cart via chat

Cart Page

Users can view cart, update quantities, or get recommendations

Homepage

Users can start browsing or searching products via chat

🔄 Navigation Patterns

Chat to Product Page

When AI shows products, users can click product links to navigate to product detail pages. Chat remains accessible via floating button.

Chat to Cart

After adding items via chat, users can navigate to cart page. Chat history preserved when returning.

Persistent Chat

Chat state persists across page navigation. Users can continue conversations seamlessly.

📱 Mobile Navigation

📱
Full-Screen Chat
On mobile, chat can open full-screen for better usability
