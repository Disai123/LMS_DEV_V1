Navigation Flow

The assistant sits inside the existing store. Users can open it from the main entry point or a product page. Store navigation stays the same. The assistant does not replace cart or checkout pages.

🗺️ Chat Integration Points

Global Access

One assistant entry point available from the existing store pages

Product Page

Users can ask about that product's manuals, FAQs, or warranty. Product context is passed to POST /rag/ask.

Existing cart and checkout

Those pages stay unchanged. The assistant does not manage cart items.

Homepage

Users can ask a product-manual question from the assistant entry point

🔄 Navigation Patterns

Assistant to product page

Users can still open the existing product page. The assistant stays available and can use that product context.

Store flows stay separate

Cart and checkout remain the existing store screens. The assistant only answers from manuals.

Persistent Chat

Chat state persists across page navigation. Users can continue conversations seamlessly.
