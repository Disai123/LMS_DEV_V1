User Experience Flow

These flows show how a customer asks a product-manual question and sees a grounded answer with citations. The assistant does not manage the cart. It answers from approved documents.

📘 Ask About a Manual

1
User opens the assistant
Sees a simple question box on the store or a product page
↓
2
User asks a question
Example: "How do I pair these wireless headphones?"
↓
3
React calls POST /rag/ask
Loading state while FAISS retrieval and the RAG agent run
↓
4
Grounded answer + citations
Answer text plus document name and section

🛒 Ask From a Product Page

1
User is on a product page
Existing catalog page stays as it is
↓
2
Question includes product context
POST /rag/ask sends the existing product id when available
↓
3
FAISS search prefers that product's manuals
Answer cites the matching usage guide or warranty section

⚠️ Empty, Clarification, and Error States

Not in the manuals

When FAISS finds no useful approved content

Assistant: "That information is not in the approved product documents."
Out of scope

When the user asks about an order or cart action

Assistant: "I answer from product manuals. I cannot look up orders or change the cart."
Service error

When FastAPI or retrieval fails

Assistant: "I could not search the manuals just now. Please try again."
Vague question

When the product is unclear

Assistant: "Which product are you asking about?"

💬 Cited Answer Example

How do I pair the wireless headphones?
Hold the power button until the LED flashes blue, then select the headphones in your device Bluetooth list.
Source: Headphones User Manual, Pairing
