Chat Interface Design

Ask the Store uses a simple chat panel inside the existing React store. The panel has a question box, an Ask button, and an answer area. It is not a new website and it does not offer cart actions.

📍 Placement in the Existing App

Where it appears
  • Host: Existing ReactJS store
  • Access: After the current login
  • Look: Same header, colors, and type
  • Scope: Questions only, read-only answers
What it does not do
  • Does not rebuild the store UI
  • Does not add a second frontend
  • Does not add or remove cart items
  • Does not show secrets or SQL

💬 Ask the Store Panel

Layout
  • Structure: Title, answer area, input, Ask button
  • Width: Fits the existing page content
  • Background: Same surface as the store
  • Title: Ask the Store
Header
  • Text: Ask the Store
  • Note: Read-only store questions
  • Style: Match existing page headings
  • No extra chrome: Keep the panel simple
Answer Area
  • Empty: Short prompt to ask about the store
  • Answer: Plain text from POST /agent/ask
  • No-data: Clear "no matching data" message
  • Out-of-scope: Agent only answers about the store
Input Area
  • Question box: One text field
  • Ask button: Disabled while loading or empty
  • Placeholder: "Ask about products, stock, or orders"
  • Submit: POST /agent/ask with the signed-in session

💭 Question and Answer Styles

User Question
  • Alignment: Right-aligned or labeled as You
  • Background: Existing primary color
  • Content: The typed store question
  • Max width: Fit the existing content column
Agent Answer
  • Alignment: Left-aligned
  • Background: Neutral surface from the store theme
  • Content: Factual answer from store data
  • Never shown: Secrets, SQL, stack traces, prompts

⏳ Loading and Status Messages

Loading
  • Shown after Ask is pressed
  • Ask button stays disabled
  • Uses the existing spinner style
Safe Error
  • Friendly message only
  • No stack traces or config
  • User can ask again
Empty State
  • Invite a store question
  • Examples: products, stock, orders
  • Remind that answers are read-only
