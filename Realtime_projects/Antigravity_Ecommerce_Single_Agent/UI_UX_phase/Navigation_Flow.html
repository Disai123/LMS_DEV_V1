Navigation Flow

Ask the Store is added to the existing React navigation. Users still shop with the current catalog, cart, and checkout screens. The agent only answers questions.

🗺️ Where Users Open Ask the Store

After Login

The existing login is required. Unauthenticated users cannot call POST /agent/ask.

Product Pages

Users can ask about a product or its stock, then return to the existing product page to buy.

Orders and Admin

Permitted users can ask about orders, customers, or sales totals. Existing order screens stay the source of truth for changes.

Homepage

Users can open Ask the Store from the existing home or nav without leaving the React app.

🔄 Navigation Patterns

Ask the Store to Product Page

After a product answer, the user can open the existing product page. The agent does not add the item to the cart.

Ask the Store to Cart or Checkout

Cart add, update, and checkout stay on the existing store screens. The agent refuses write requests.

Stay Inside One App

Navigation uses the current React routes. There is no second site or second login.

📱 Mobile Navigation

📱
Same React Layout
On mobile, Ask the Store uses the existing responsive layout. It does not become a separate app.
⌨️
Keyboard Handling
The question input stays visible when the mobile keyboard opens.
👆
Touch Targets
The Ask button and nav links meet the existing 44px tap target size.
