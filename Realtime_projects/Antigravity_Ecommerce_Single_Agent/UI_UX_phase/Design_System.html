Design System

Ask the Store reuses the existing React store design system. New styles are limited to the question box, Ask button, and answer area. Do not introduce a separate visual language.

🎨 Color Palette

Primary Blue

#3B82F6

Ask button and user question, matching the store

Agent Answer

#F3F4F6

Answer surface from the existing theme

Success

#10B981

Optional success hint when an answer is ready

Error

#EF4444

Safe error and refusal emphasis

Background

#FFFFFF

Same page background as the store

Text

#374151

Primary text used across the existing app

📝 Typography

Font Family
Inter — reuse the store body font
Poppins — reuse the store heading font if already in use
Font Sizes
Answer text: 0.875rem (14px) — same as existing body copy
Question input: 1rem (16px) — matches existing form fields
Heading: 1.125rem (18px) — Ask the Store title

🧩 Ask the Store Components

Ask Button
  • Reuse the existing primary button
  • Disabled when empty or loading
  • Label: Ask
Answer Block
  • Plain text from the agent
  • No-data and refusal variants
  • No invented product cards
Question Input
  • Same input style as the store forms
  • Placeholder for store questions
  • Disabled while a request is running
Loading Indicator
  • Reuse the existing spinner
  • Shown during POST /agent/ask
  • Does not reveal internal steps

📱 Responsive Design

Desktop (≥ 768px)
  • Panel sits in the existing page column
  • Question input and Ask button stay on one row when space allows
  • Answer area uses the same max width as other store content
Mobile (< 768px)
  • Stack the input and Ask button
  • Keep tap targets at least 44px
  • Avoid covering the existing store navigation
