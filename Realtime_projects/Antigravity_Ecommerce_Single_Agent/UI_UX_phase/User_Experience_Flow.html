User Experience Flow

These flows show how a signed-in user asks the existing store a question. The agent only reads approved data. It never adds items to the cart or changes an order.

🔍 Product Question Flow

1
User Signs In
Uses the existing store login, then opens Ask the Store
↓
2
User Types a Question
Example: "How many products are in the store?"
↓
3
React Calls FastAPI
Loading state is shown while POST /agent/ask runs
↓
4
Agent Answers from Store Data
LangGraph reads approved PostgreSQL data and returns a factual answer

📦 Stock or Order History Flow

1
User Asks a Data Question
"Show the stock for Premium Wireless Headphones"
↓
2
Scope Check
LangGraph confirms this is an allowed store question
↓
3
Read-Only Data Access
Approved store tables are read. Nothing is written.
↓
4
Grounded Answer
The UI shows the real stock or order figure, or a no-data message

⚠️ Status and Refusal Flow

No Matching Data

When the database has no matching row

Agent: "No matching data was found for that question."
Write Request Refused

When the user asks to change the cart or an order

Agent: "Ask the Store is read-only. I can answer questions about store data, but I cannot change the cart or orders."
Model or Database Failure

When LangGraph or PostgreSQL fails

Agent: "I could not complete that request. Please try again."
Unclear Question

When the store question is incomplete

Agent: "Which product or category do you mean? Please give a name."
