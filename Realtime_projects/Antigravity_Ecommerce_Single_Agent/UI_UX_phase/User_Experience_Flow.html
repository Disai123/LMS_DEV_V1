User Experience Flow

User experience flows define how customers interact with the AI agent through various scenarios. These flows ensure smooth, intuitive conversations that guide users to their goals.

🔍 Product Search Flow

1
User Opens Chat
Clicks chat button, sees welcome message
↓
2
User Types Query
Example: "Show me laptops under $1000"
↓
3
AI Processes Request
Loading indicator shown, AI calls searchProducts tool
↓
4
AI Responds
Displays product list with details (name, price, stock)

🛒 Add to Cart Flow

1
User Requests Add
"Add the first laptop to my cart"
↓
2
AI Confirms
AI confirms product selection before adding
↓
3
Stock Check
AI verifies product is in stock
↓
4
Item Added
AI confirms addition with cart summary

⚠️ Error Handling Flow

Product Not Found

When user searches for non-existent product

AI: "I couldn't find that product. Would you like to search for something similar?"
Out of Stock

When user tries to add out-of-stock item

AI: "Sorry, that product is currently out of stock. Would you like to see similar products?"
API Error

When OpenAI API fails

AI: "I'm having trouble processing that. Please try again in a moment."
Ambiguous Query

When user query is unclear

AI: "Could you clarify what you're looking for? For example, are you looking for a specific brand or price range?"

Show me electronics
