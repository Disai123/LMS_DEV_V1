Ask the Store Deployment Planning

Deploy Ask the Store with the existing application approach. FastAPI and React go to Render. PostgreSQL/Neon stays the store database. Do not add a second backend.

Local

Requirements: existing FastAPI app, existing React app, PostgreSQL/Neon, configured LLM via LangChain
Check: store starts, login works, POST /agent/ask returns a grounded answer

Render

Services: FastAPI web service and React static or Node service
Database: existing PostgreSQL/Neon
Observability: Langfuse traces after the feature is stable

Post-deploy checks

  • Sign in with the existing login
  • Ask a product question and a stock question
  • Confirm a write request is refused
  • Confirm catalog, cart, checkout, and admin still work
  • If the store breaks, roll back only the agent change
