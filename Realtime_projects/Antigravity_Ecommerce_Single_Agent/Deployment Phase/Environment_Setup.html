Environment Setup

Configure local and Render environments for Ask the Store on the existing FastAPI and React application. Put secrets in environment variables only. Do not copy real keys into DEPLOYMENT.md.

Required values

# Backend (existing FastAPI)
DATABASE_URL=postgresql://...          # existing PostgreSQL/Neon
LLM_API_KEY=your-configured-llm-key    # used by LangChain / LangGraph
LANGFUSE_PUBLIC_KEY=                   # added when tracing is enabled
LANGFUSE_SECRET_KEY=
LANGFUSE_HOST=

# Frontend (existing React)
VITE_API_BASE_URL=https://your-fastapi-service.onrender.com

Setup notes

  • Reuse the existing login configuration. We do not use a separate identity service.
  • Point the React build at the existing FastAPI service, including POST /agent/ask
  • Keep development, staging, and production secrets separate
  • Langfuse keys are optional until Day 17 tracing is implemented
