This phase deploys Ask the Store with the existing application. FastAPI, React, LangGraph, Langfuse, and PostgreSQL go to Render. Do not create new infrastructure unless the current project already requires it.

Phase Objectives

  • Record backend and frontend environment values in DEPLOYMENT.md
  • Start FastAPI and serve the existing React build
  • Confirm PostgreSQL/Neon access without putting secrets in the document
  • Deploy the agent without breaking catalog, cart, checkout, or admin
  • Run post-deployment checks on POST /agent/ask
  • Document how to roll back the agent change

Deliverables

  • DEPLOYMENT.md for Ask the Store
  • Render environment notes for FastAPI and React
  • PostgreSQL/Neon and Langfuse configuration pointers
  • Post-deploy checks and rollback steps
