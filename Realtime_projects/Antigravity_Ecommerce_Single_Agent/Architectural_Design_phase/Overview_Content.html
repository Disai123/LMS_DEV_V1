Architecture Overview

Project Video

This phase records the architecture for Ask the Store. The agent is added to the existing store. The path is: React chat UI → FastAPI POST /agent/ask → LangGraph → approved store data → PostgreSQL/Neon → answer. Langfuse is used later for tracing. We do not create a second backend or database.

Architecture Layers

Frontend
Existing React chat UI
API Layer
Existing FastAPI POST /agent/ask
Agent Flow
LangGraph + configured LLM via LangChain
Store Data
Read-only products, orders, stock
Database
Existing PostgreSQL/Neon

Deliverables

  • ARCHITECTURE.md for Ask the Store
  • End-to-end request path
  • Reuse of existing login and PostgreSQL tables
  • Read-only data access rules
  • Error, refusal, and request-id notes
  • Langfuse tracing later
