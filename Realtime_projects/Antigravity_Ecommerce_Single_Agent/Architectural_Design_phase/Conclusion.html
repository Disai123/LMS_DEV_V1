Conclusion

The architecture for Ask the Store is a single read-only path through the existing application. React sends a question to FastAPI. LangGraph reads approved PostgreSQL data and returns a safe answer. Langfuse is added later for tracing.

Key Architecture Decisions

  • ✅ React chat UI → FastAPI POST /agent/ask → LangGraph → approved store data → PostgreSQL → answer
  • ✅ Reuse existing login, permissions, and FastAPI middleware
  • ✅ Configured LLM via LangChain, used by the LangGraph flow
  • ✅ Read-only data path; no cart or order writes
  • ✅ Existing PostgreSQL/Neon tables; we do not use a second database
  • ✅ Clear refusals for out-of-scope and write requests
  • ✅ Langfuse for traces after the feature works
