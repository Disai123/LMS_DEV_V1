AI Integration Architecture

The AI integration architecture defines how OpenAI GPT models are integrated into the system, including function calling, context management, and tool execution patterns.

🤖 OpenAI Configuration

Model Selection
  • Model: gpt-4o-mini (cost-effective, fast)
  • API Key: Stored in environment variable (OPENAI_API_KEY)
  • Temperature: 0.7 (balanced creativity/consistency)
  • Max Tokens: 1000 (sufficient for responses)
System Prompt

Defines AI personality and behavior: 

"You are askunicart, the friendly shopping assistant. 
You help customers browse products, check stock, 
recommend products, and manage carts..."

🔧 Function Calling (Tools)

Available Tools
searchProducts
Search products by query, category, price
getProductDetails
Get detailed product information
checkStock
Check product availability
getRecommendations
Get product recommendations
addToCart
Add product to cart
getCart
Get cart contents
updateCartItem
Update cart item quantity
removeFromCart
Remove item from cart
Tool Execution Flow
1. AI decides to call a tool
2. Tool function executed with parameters
3. Tool result returned to AI
4. AI generates response using tool result
5. Response sent to user

💾 Context Management

Conversation History

Last 20 messages loaded from database and sent to OpenAI as context. This enables multi-turn conversations while limiting token usage.

Message Format
[
  { role: "system", content: "System prompt..." },
  { role: "user", content: "Message 1" },
  { role: "assistant", content: "Response 1" },
  { role: "user", content: "Message 2" }
]
Token Optimization
  • Limit context to 20 messages
  • Truncate very long messages if needed
  • Use concise tool descriptions
  • Monitor token usage per request

⚙️ Error Handling

API Errors

Handle OpenAI API failures gracefully with retry logic and user-friendly error messages.

Tool Errors

Catch tool execution errors and inform AI, allowing it to provide alternative responses.

Timeout Handling

60-second timeout for AI requests. Return timeout error if exceeded.
