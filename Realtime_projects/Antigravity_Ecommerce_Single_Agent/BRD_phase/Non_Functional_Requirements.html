Non-Functional Requirements

These requirements set quality limits for Ask the Store. The agent must stay safe, read-only, and within the existing FastAPI, React, and PostgreSQL application.

⚡ Performance Requirements

ID Requirement Target Priority
NFR-PF-001 Agent Response Time Keep query time under a safe project limit High
NFR-PF-002 Approved Data Read Time Read-only queries stay small and bounded High
NFR-PF-003 Database Query Latency Use the existing PostgreSQL/Neon connection Medium
NFR-PF-004 Input and Result Size Limit question length, result size, and retries Medium
NFR-PF-005 Ask the Store UI Load Chat screen loads with the existing React app High

📈 Scalability Requirements

ID Requirement Target Priority
NFR-SC-001 Reuse Existing Capacity Run the agent on the existing FastAPI service High
NFR-SC-002 Request Limits Keep retries and result size under safe limits Medium
NFR-SC-003 Database Connections Reuse the existing PostgreSQL/Neon pool High

🔒 Security Requirements

ID Requirement Description Priority
NFR-SE-001 Reuse Existing Login POST /agent/ask uses the current authentication and roles High
NFR-SE-002 Secret Protection Never expose API keys, tokens, passwords, or database credentials High
NFR-SE-003 Permission Boundaries Customer and admin data access follows existing authorization High
NFR-SE-004 Untrusted Input Treat questions as untrusted and block prompt injection High
NFR-SE-005 Read-Only Data Path Agent data access is read-only and cannot modify store tables High
NFR-SE-006 Safe Responses No SQL, stack traces, system prompts, or internal config in replies High

🔄 Availability Requirements

ID Requirement Target Priority
NFR-AV-001 Existing App Stability Adding the agent must not break the live store High
NFR-AV-002 Safe Error Messages Users see a simple message on model, database, or timeout failure High
NFR-AV-003 Model or Database Failure LangGraph stops safely; the rest of the store keeps working Medium

✨ Usability Requirements

ID Requirement Description Priority
NFR-US-001 Match Existing React UI Simple question box, Ask button, and answer area in the current app High
NFR-US-002 Loading State Show a loading state while POST /agent/ask is running High
NFR-US-003 Clear Outcome Messages No-data, out-of-scope, and error messages are easy to read High
NFR-US-004 Mobile Layout The Ask the Store screen remains usable on small screens Medium
