Project Overview

Project Video

This phase writes the Business Requirements Document (BRD) for Ask the Store. Ask the Store is one read-only AI agent added to an existing e-commerce application. The BRD records the business problem, in-scope questions, out-of-scope limits, and what existing parts of the store must stay unchanged.

Phase Objectives

  • Define the goal of Ask the Store on the existing React and FastAPI store
  • List in-scope questions: products, categories, customers, orders, stock, and sales totals
  • Record the read-only rule: the agent must not change store data
  • Reuse existing login, permissions, and the PostgreSQL/Neon database
  • Write user stories for store questions and out-of-scope refusals
  • Set success criteria that answers match real database data

What is Ask the Store?

Ask the Store is a single read-only agent inside the existing store. A signed-in user asks a question in natural language. The agent reads approved store data and returns a short, factual answer. It does not add items to a cart, change orders, or invent numbers.
