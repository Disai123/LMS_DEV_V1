Testing Overview

Project Video

This phase tests Ask the Store against real store data in PostgreSQL. Each answer is compared with the database or with the expected refusal. Results stay in TESTING.md.

Testing Objectives

  • Confirm product, category, customer, order, stock, and sales answers match the database
  • Confirm POST /agent/ask requires the existing login
  • Confirm no-data and out-of-scope messages
  • Confirm the React screen shows the real backend answer
  • Confirm existing catalog, cart, checkout, and admin still work
  • Confirm prompt-injection and write requests are refused

Testing Types

Unit Testing
LangGraph nodes and read path
Integration Testing
POST /agent/ask and PostgreSQL
UI Testing
Ask the Store in React
Performance Testing
Limits, timeouts, result size
