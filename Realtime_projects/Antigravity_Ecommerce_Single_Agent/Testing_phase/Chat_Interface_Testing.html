Ask the Store UI Testing

Browser tests cover the Ask the Store screen inside the existing React app. The UI must show the real POST /agent/ask answer and must not offer cart mutations.

Screen Checks

  • ✅ Ask the Store opens after the existing login
  • ✅ Question input, Ask button, and answer area are visible
  • ✅ Loading state appears while the request is running
  • ✅ A product question shows the backend answer
  • ✅ A no-data question shows the no-data message
  • ✅ An unrelated question shows the out-of-scope message
  • ✅ A failure shows a safe error, not a stack trace

Existing Store Checks

  • ✅ Products, Cart, Checkout, Orders, and Admin still work
  • ✅ The agent does not add or remove cart items
  • ✅ Mobile layout still fits the existing React theme
