Unit Testing

Unit tests cover LangGraph steps and the read-only store data helpers. They do not test cart add or remove because those actions are out of scope.

📚 Product and Category Reads

Product Lookup Tests
  • ✅ Product count matches the database
  • ✅ Category filter returns only that category
  • ✅ Missing product returns no-data
  • ✅ Result size stays within the approved limit
Product Details Tests
  • ✅ Returns name and price from the existing row
  • ✅ Does not invent missing fields
  • ✅ Does not return SQL or secrets

🛡️ Scope and Refusal Tests

Write Request Tests
  • ✅ "Add this to my cart" is refused
  • ✅ Checkout or cancel-order requests are refused
  • ✅ Store tables are unchanged after the refusal
Out-of-Scope Tests
  • ✅ Unrelated questions get a polite refusal
  • ✅ Prompt-injection attempts are refused
  • ✅ Unclear questions ask for clarification

📦 Stock and Totals Tests

Read-Only Number Tests
  • ✅ Stock matches the product row
  • ✅ Zero stock is reported as zero
  • ✅ Order counts and sales totals match stored orders
  • ✅ Date-range totals use only stored order dates

🔐 Validation Tests

Input and Access Tests
  • ✅ Empty or oversized questions are rejected
  • ✅ Unapproved tables or columns are blocked
  • ✅ Existing permissions still hide unauthorized customer data
