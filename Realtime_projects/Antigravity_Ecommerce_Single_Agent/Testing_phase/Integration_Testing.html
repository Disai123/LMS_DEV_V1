Integration Testing

Integration tests call the existing FastAPI backend. They send questions to POST /agent/ask, run LangGraph, and compare the answer with PostgreSQL.

POST /agent/ask

Authenticated store question
  • ✅ Existing login is accepted
  • ✅ A product question returns the real count or list
  • ✅ An order or stock question matches the database
  • ✅ The response has no SQL, stack traces, or secrets

Authentication and Input

  • ✅ Missing login returns a clear unauthenticated response
  • ✅ Empty or invalid question returns 400-style feedback
  • ✅ Existing customer and admin APIs still respond as before

LangGraph and Database

  • ✅ The graph reads approved tables only
  • ✅ No-data questions return a no-data status
  • ✅ Out-of-scope questions are refused
  • ✅ Model or database failures return a safe message
  • ✅ Store rows are unchanged after each test
