Backend Development

The backend change lives inside the existing FastAPI application. Add POST /agent/ask, reuse current authentication, and run a LangGraph flow that only reads store data. Do not create a second backend.

POST /agent/ask Flow

The handler authenticates the user, accepts a question, runs LangGraph, and returns a safe answer. Existing customer and admin APIs stay unchanged.

Handler Flow 
@router.post("/agent/ask")
async def ask_the_store(body, user = Depends(current_user)):
    question = validate_question(body.question)
    result = await run_langgraph(question, user)
    return {"answer": result.answer, "status": result.status}
