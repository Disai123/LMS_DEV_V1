Approved Store Data Access

Ask the Store does not add cart-writing tools. LangGraph uses a small set of read-only data steps for products, categories, customers, orders, stock, and sales totals.

📚 Product Lookup

Reads the existing product catalog. Answers counts, names, prices, and category lists from real rows.

count_products · list_products_in_category · get_product_details

📦 Stock Questions

Reads current stock for a selected product. Zero stock is reported as zero. Stock is never reserved or changed.

get_stock_for_product

📋 Orders and Sales Totals

Reads allowed order history, order-item counts, and sales totals. Date-range questions use stored order dates only.

count_orders · get_order_totals · get_allowed_order_history

🛡️ Refusals

Write requests and unrelated questions are refused. The agent does not add, update, or remove cart items.

refuse_write
refuse_out_of_scope
no_data_found
