Day 1: ANTIGRAVITY TASK-WISE PROMPT GUIDE

ANTIGRAVITY TASK-WISE PROMPT GUIDE

Single Agent Integration into Existing E-Commerce Application
FastAPI + ReactJS + LangGraph + Langfuse
Purpose
This guide gives one clear Antigravity prompt for each day. The first 3 days are only for understanding the agent concepts needed for the project. Days 4-20 build and finish one simple agent feature inside the existing e-commerce application.
Final Project
Add one feature called "Ask the Store".
The agent answers questions about real e-commerce data such as products, categories, customers, orders, stock and sales totals.
Backend must use the existing application backend with FastAPI.
Frontend must use the existing ReactJS application.
Use LangGraph for the agent flow.
Use Langfuse for AI workflow tracing and evaluation support.
Reuse the existing login, permissions and PostgreSQL/Neon database.
Only Required Project Documents
Keep only these six project documents. Do not create extra permanent markdown files.
BRD.md
UI_UX.md
ARCHITECTURE.md
CODING.md
TESTING.md
DEPLOYMENT.md
Temporary File Rule
Antigravity may create temporary test scripts, temporary JavaScript files, sample data, screenshots or debugging files when needed. After the related testing/debugging is complete, delete those temporary files. Do not leave unnecessary test files or extra documentation in the final project.
Important Working Rules
Do not rebuild the existing e-commerce application.
Do not create a second backend or second database.
Reuse the existing authentication and authorization.
Do one task per day. Do not continue to the next day automatically.
Use simple functionality first. Do not add features that are not required.
Do not create multiple documents for the same purpose.
Do not change existing e-commerce features unless the current task requires it.
The agent must use real database data and must not invent answers.
Protect secrets, customer information and internal system details.
