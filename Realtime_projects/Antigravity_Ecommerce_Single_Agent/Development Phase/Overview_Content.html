Development Overview

Project Video

Development adds Ask the Store to the existing FastAPI backend and React frontend. First we add a LangGraph flow and POST /agent/ask. Then we connect a read-only path to PostgreSQL. The React screen is built last and only after the endpoint works.

Development Steps

1
FastAPI Agent Structure
Add LangGraph, reuse login, and create a read-only data path. Do not create a second backend.
2
POST /agent/ask
Accept a question, run LangGraph, return a grounded answer from PostgreSQL.
3
React Ask the Store UI
Add a simple question box and answer area inside the existing React app.

Quality Standards

  • ✅ Existing authentication on POST /agent/ask
  • ✅ Read-only queries only; no cart or order writes
  • ✅ Answers match real database rows or say no data was found
  • ✅ Existing catalog, cart, checkout, and admin still start and work
