Database Implementation

The data layer uses PostgreSQL via Prisma ORM. We implement Conversation and Message models that persist chat history, and integrate with the existing e-commerce product and cart tables.

// Prisma Schema — Conversation Model
model Conversation {
id String @id @default(cuid())
userId String // Bound to JWT user
messages Message[]
createdAt DateTime @default(now())
}

The implementation focuses on user-bound data isolation — every query is scoped by userId extracted from the validated JWT token, ensuring no cross-user data leakage.

Implementation Highlights

Prisma for type-safe, non-blocking database operations.
Prisma Migrate for managed schema versioning and migrations.
Message history capped at 20 records to control token usage.
Cascade delete on Conversation ensures clean message cleanup.
