Database Implementation

Ask the Store reuses the existing PostgreSQL/Neon connection. The agent reads products, categories, customers, orders, order items, and stock. It does not add a second database and it does not write store rows.

# Read-only agent query example
SELECT name, price, stock
FROM products
WHERE category = :category
LIMIT approved_max
# Never shown to the user. Writes are not allowed.

Queries stay on an approved field list and use the signed-in user's permissions. If no row matches, the agent says so. It never invents a count or total.

Implementation Highlights

Reuse the existing FastAPI database connection.
Keep a separate read-only path for the agent.
Bound result size so answers stay small and safe.
Leave existing store tables and APIs unchanged.
