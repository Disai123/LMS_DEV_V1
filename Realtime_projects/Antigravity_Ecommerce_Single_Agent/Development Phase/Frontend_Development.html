Frontend Development

The frontend is a React 18 + Next.js 14 floating chat widget. It uses Zustand for global state management, providing a seamless shopping assistant interface accessible from any page of the e-commerce storefront.

Chat Component Architecture

AskUnicartChat.tsx is a floating button component. On click it expands into a full chat window with message history, loading states, and an input field that posts to the backend API route.

Zustand Store State

The global chat store manages all conversation state. The UI stays in sync without any manual page refreshes or prop drilling.
