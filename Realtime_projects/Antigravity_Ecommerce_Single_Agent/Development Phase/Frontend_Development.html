Frontend Development

The frontend change is a simple Ask the Store screen inside the existing ReactJS application. Reuse the current styling and login. Do not create a separate frontend.

Ask the Store Screen

The screen has a question input, an Ask button, a loading state, and an answer area. It posts the question to the existing FastAPI endpoint and shows the real backend reply.

Ask action 
const response = await fetch('/agent/ask', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    credentials: 'include',
    body: JSON.stringify({ question })
});
