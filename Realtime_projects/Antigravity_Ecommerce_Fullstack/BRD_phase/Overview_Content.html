Project Overview

Project Video

This phase writes BRD.md for ShopEasy. The store uses ReactJS, FastAPI, and PostgreSQL, and it is live on Render. Keep the scope small: customer shopping and admin catalog/order work. Do not add extra features.

Phase Objectives

  • State the project goal and the two user types: customer and admin
  • List in-scope customer and admin journeys
  • Write functional requirements that match the real store
  • Write simple non-functional needs for a Render-hosted app
  • Record success criteria: the main flows work end to end

Deliverables

  • BRD.md with goal, users, in scope, and out of scope
  • Customer journey: register through order history
  • Admin journey: login, products, categories, order status
  • Functional requirements for cart, checkout, and catalog
  • Simple success criteria for the live Render app
