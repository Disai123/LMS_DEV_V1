E-Commerce Deployment Planning

Run React and FastAPI locally, then deploy both services and PostgreSQL on Render.

Deployment Possibilities

Local Development
💻 Local Machine Setup
Purpose: Development and testing
Requirements: Python, PostgreSQL, Git, and a React build toolchain
Benefits: Fast development, offline work
Limitations: Single user, limited scalability
🐳 Docker Local Setup
Purpose: Containerized development
Requirements: Docker, Docker Compose
Benefits: Consistent environment, easy setup
Use Case: Team development, production-like setup
Cloud Deployment
☁️ Render Deployment
Services: Web Service (FastAPI), Static Site (React), PostgreSQL
Benefits: One host for frontend, backend, and database
Cost: Free tier for student projects
Best For: The live ShopEasy demo
🌐 Render Hosting
Services: Render dashboard, GitHub auto-deploy
Benefits: Connect DATABASE_URL and FRONTEND_URL
Cost: Free PostgreSQL instance for development
Best For: FastAPI + React student apps

Local Deployment Setup

Prerequisites Installation
Python and React tooling
# Install Python 3 and create a virtual environment
python -m venv .venv
# Windows: .venv\Scripts\activate
source .venv/bin/activate
pip install fastapi uvicorn sqlalchemy psycopg2-binary alembic python-jose passlib

# React frontend uses npm only for the UI
# (install Node separately if you need the React build tools)
PostgreSQL Installation
# Install PostgreSQL
sudo apt update
sudo apt install postgresql postgresql-contrib

# Start PostgreSQL service
sudo systemctl start postgresql
sudo systemctl enable postgresql

# Create database and user
sudo -u postgres psql
CREATE DATABASE ecommerce_db;
CREATE USER ecommerce_user WITH PASSWORD 'your_password';
GRANT ALL PRIVILEGES ON DATABASE ecommerce_db TO ecommerce_user;
E-Commerce Application Setup
Clone and Install Dependencies
# Clone the repository
git clone https://github.com/your-username/ecommerce-app.git
cd ecommerce-app

# Install dependencies
npm install   # React frontend dependencies

# Install Alembic globally
pip install fastapi uvicorn sqlalchemy psycopg2-binary alembic
Environment Configuration
# Create environment file
cp .env.example .env

# Configure environment variables
DATABASE_URL="postgresql://ecommerce_user:your_password@localhost:5432/ecommerce_db"
JWT_SECRET="your-fastapi-jwt-secret"
FRONTEND_URL="http://localhost:3000"
SECRET_KEY="your-app-secret"
VITE_API_BASE_URL="http://localhost:8000"
Database Setup and Migration
# Generate SQLAlchemy session
alembic upgrade head

# Run database migrations
alembic upgrade head

# Seed the database with sample data
python seed.py

# Start FastAPI, then the React frontend
uvicorn main:app --reload
npm run dev
