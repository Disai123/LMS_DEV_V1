Architectural Design Overview

Project Video

This phase describes the ShopEasy stack: React frontend, FastAPI backend, PostgreSQL, and Render hosting. Auth uses FastAPI JWT. Checkout is a simple place-order flow, not a payment gateway.

Phase Objectives

  • Show React calling FastAPI, and FastAPI talking to PostgreSQL
  • Design tables for users, categories, products, cart, and orders
  • List FastAPI routes for auth, catalog, cart, checkout, and admin
  • Document JWT auth and admin role checks
  • Plan a Render deploy for frontend, backend, and the database

Deliverables

  • System Architecture Diagram
  • Database Schema Design
  • API Documentation
  • Security Architecture Plan
  • Technology Stack Specification
  • Deployment Architecture
