Frontend Development

React pages call FastAPI. Customers browse, search, manage the cart, check out, and view orders. Admins manage products, categories, and order status.

Detailed Folder Structure & Descriptions

📄
Pages Directory (src/pages/)

Contains all application pages and routing components using React Router

Customer Pages
  • • Home.jsx - Homepage with product highlights
  • • Products.jsx - Product catalog and search
  • • ProductDetails.jsx - Product details
  • • Cart.jsx - Cart quantity and remove
  • • Checkout.jsx - Delivery details and place order
  • • Login.jsx - Customer and admin login
  • • Register.jsx - Customer registration
Admin Pages
  • • Profile.jsx - Customer profile
  • • Orders.jsx - Order history
  • • AdminProducts.jsx - Product CRUD
  • • AdminCategories.jsx - Category CRUD
  • • AdminOrders.jsx - View and update orders
🧩
Components Directory (components/)

Reusable UI components organized by functionality

Layout Components
  • • layout/Header.jsx - Navigation header
  • • layout/Footer.jsx - Site footer
  • • context/AuthContext.jsx - JWT session
UI Components
  • • ui/Button.jsx - Reusable buttons
  • • ui/ProductCard.jsx - Product cards
  • • ui/Input.jsx - Form inputs
  • • ui/Badge.jsx - Order status badges
  • • ui/Label.jsx - Form labels
E-commerce Features
  • • Product listing components
  • • Shopping cart functionality
  • • Checkout process components
  • • Place-order form (no payment gateway)
  • • Order management
🔌
API Client (src/api/)

React calls FastAPI routers. Routes live on the Python backend, not in the frontend.

E-commerce APIs
  • • products.js - GET /api/products
  • • cart.js - Cart add, update, remove
  • • orders.js - Checkout and order history
  • • auth.js - Register, login, profile
Admin APIs
  • • adminProducts.js - Admin product CRUD
  • • adminCategories.js - Admin category CRUD
  • • adminOrders.js - View orders and update status

Technology Stack

⚛️
ReactJS

React SPA with React Router. Pages call FastAPI over HTTPS.

🎨
Tailwind CSS

Utility-first CSS framework for rapid UI development

🔄
React Router

Client routes for shop, cart, checkout, orders, and admin pages

📊
SQLAlchemy

Used only on the FastAPI backend. The React app calls HTTP APIs.
