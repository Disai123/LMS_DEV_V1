Testing & QA

Testing in an agentic system requires a multi-layered approach to ensure reliability. We implement traditional unit tests alongside specialized agentic evaluation patterns.

Backend Unit Tests

Focuses on tool reliability and orchestrator logic. We use Pytest to mock LLM responses and verify worker transitions.

pytest tests/test_graph.py

Frontend Verification

Ensures reactive components synchronize with the agent stream. We use Vitest and Playwright for E2E flows.

npm run test:e2e

Agentic Evaluation (Eval-as-a-Service)

Beyond unit tests, we run specialized evals to measure reasoning accuracy and trajectory consistency. This ensures the Supervisor doesn't hallucinate tool arguments or get stuck in recursive loops.

  • • Trajectory Matching: Does the worker path match the expected blueprint?
  • • Tool Input Accuracy: Does the agent provide valid product IDs?
  • • Policy Compliance: Does the assistant refuse to perform unauthorized actions?
