Backend Development

The backend is a fusion of FastAPI and LangGraph. We implement an event-driven orchestrator that streams agent reasoning directly to the client.

Orchestration Hub

The core logic resides in a state-graph. The Supervisor node uses an LLM to decide whether to call a tool, delegate to a worker, or respond to the user.

Worker Delegation Logic 
def supervisor_node(state):
    # Analyze state and decide next move
    prediction = llm.with_structured_output(Router).invoke(state["messages"])
    if prediction.next == "FINISH":
        return END
    return prediction.next # search_worker | cart_worker
