Agentic Development Phase

Development in this project focuses on merging traditional API patterns with Probabilistic Logic. We build the deterministic tools first, followed by the orchestrator graph that decides when to use them.

Development Steps

1
Tool Development
Implementing Search, Cart, and User Profiler tools using Pydantic.
2
LangGraph Pipeline
Wiring the Supervisor and Workers into a stateful, cyclic graph.
3
Reactive UI Widget
Integrating the React components with SSE streams for token-by-token rendering.
