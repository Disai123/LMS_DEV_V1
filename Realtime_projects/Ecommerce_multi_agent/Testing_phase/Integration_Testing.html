Integration Testing

Integration tests verify the complex interactions between the Supervisor, Workers, and the Database. We must ensure the graph state remains consistent during multi-turn reasoning across these layers.

Scenario: Search-to-Cart Pipeline
  1. User asks for "Black Sneakers".
  2. Supervisor invokes search_worker.
  3. search_worker calls get_products and returns 2 items.
  4. User asks "Add the first one to my cart".
  5. Supervisor invokes cart_worker.
  6. cart_worker calls add_to_cart with the correct product ID.
  7. Verify DB state contains the item for the user.
