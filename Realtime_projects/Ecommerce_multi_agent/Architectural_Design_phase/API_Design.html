API Design

The system utilizes a Streaming-First API design. Interaction occurs over standard HTTP endpoints, but agent responses are delivered via server-sent events (SSE) for real-time interactivity.

POST /api/v1/chat
Main Chat Stream
Request Body 
{
  "message": "Find waterproof boots",
  "thread_id": "8b9cad-0e1f-2031",
  "user_id": 101
}
SSE Streaming Events
  • • node:supervisor - Orchestrator reasoning
  • • node:search_worker - Specialized search tokens
  • • token:... - Chunk of the final response body
GET /api/v1/cart
Cart Fetch

Returns the current state of a user's cart, often used for UI synchronization after an agent-driven cart modification.
