Environment Setup

The production environment requires a specific set of variables to enable the agentic workflows. Follow these steps to prepare your cloud environment.

1. Database Initialization

Create a PostgreSQL instance and run the migrations to initialize the product catalog and checkpoint tables.

alembic upgrade head

2. Secret Configuration

Configure the following secrets in your cloud provider's secret manager.

# .env (Production) OPENAI_API_KEY=sk-proj-... LANGCHAIN_API_KEY=lsv2_... DATABASE_URL=postgresql://user:pass@host:5432/db

3. SSE Configuration

Ensure your load balancer supports persistent HTTP connections with no timeout for the /api/v1/chat streaming endpoint.
