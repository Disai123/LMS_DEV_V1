Deployment Planning

A successful deployment of an agentic system requires careful planning of environment secrets and connectivity between the frontend, backend, and external LLM providers.

Infrastructure Choice

We have chosen Google Cloud Run for the backend to handle the asynchronous streaming nature of agentic chat, with Vercel hosting the React frontend for global edge performance.

Scaling Strategy

Horizontal scaling is implemented based on request latency. Since LLM calls are time-heavy, we scale based on active streaming connections to ensure no single instance is bottlenecked.
