Environment Setup

Environment variables are used to securely store configuration details that differ between local development and production.

Backend Variables (Render Dashboard)

CORS_ORIGINS

Set to your frontend Render URL (e.g., https://todo-app-ui.onrender.com)

DATABASE_URL

sqlite:///./data/todos.db (Paths must be absolute in production)

📦 Persistent Disk Storage

Render Web Services are ephemeral (data is lost on restart). We must mount a Render Disk at /data to ensure our SQLite database file persists across deployments.
