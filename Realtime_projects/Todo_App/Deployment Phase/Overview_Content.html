Deployment Phase

The deployment phase covers the process of moving the application from a local development environment to a production server. We use Render.com for its seamless integration with GitHub and support for both static sites and web services.

Deployment Goal

To achieve a fully automated CI/CD pipeline where every push to the main branch triggers a rebuild and redeployment of both the frontend and backend services.
