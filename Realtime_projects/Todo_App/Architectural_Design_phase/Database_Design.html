Database Design

We use SQLite 3 for its simplicity and file-based nature, which is perfect for this single-user application. The schema is highly optimized for fast CRUD operations.

Table: todo_items

Field Type Constraints
id INTEGER PRIMARY KEY, AUTOINCREMENT
title VARCHAR(200) NOT NULL
description TEXT NULLABLE
completed BOOLEAN DEFAULT FALSE

Data Integrity

Title presence is enforced at the database level to prevent empty tasks.

Persistence Model

Serialized JSON is also used in the frontend's localStorage as a session backup.
