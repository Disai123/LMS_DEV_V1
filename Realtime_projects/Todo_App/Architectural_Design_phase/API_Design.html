API Design

The application communicates via a standard RESTful API. Below are the key endpoints used for task orchestration.

GET /tasks/
Retrieves all tasks stored in the SQLite database. Supports optional query parameters for filtering (skipped in MVP).
POST /tasks/
Creates a new task. Required JSON body: {"title": "string", "description": "string"}.
PUT /tasks/{id}
Updates task status or content. Primarily used for toggling "completed" status.
DELETE /tasks/{id}
Permanently deletes the specified task from the database.
