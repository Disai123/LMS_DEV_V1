System Architecture

The system is designed for high cohesion and low coupling. Here we break down the internal structure of both the Frontend and Backend.

⚛️ Frontend (Client)

Views/Pages

Single Source of Truth (Dashboard). Uses React State for local data management.

Components

Stateless UI components for individual tasks, filtering, and input areas.

API Service

Axios/Fetch layer to communicate with the FastAPI backend via async/await.

🐍 Backend (Server)

FastAPI Router

Handles incoming HTTP requests and directs them to the correct controller logic.

CRUD Logic

Business logic layer for processing task data before database operations.

SQLAlchemy/Lite

ORM layer for interacting with the SQLite database file (`todo.db`).
