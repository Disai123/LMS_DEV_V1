Security Architecture

Even for a simple application, security is a priority. We implement standard protocols to protect data integrity and prevent common web vulnerabilities.

🛡️ CORS Management

FastAPI is configured with restricted Cross-Origin Resource Sharing. Only authorized origins (the deployed frontend URL) are allowed to make requests to the backend.

🧹 Input Sanitization

All incoming task titles and descriptions are sanitized through Pydantic models in the backend. This prevents basic XSS and SQL Injection attempts.

🔒 Secure Persistence

The SQLite database file is kept outside the public-facing web directory. Access to the database is only possible through the backend's authenticated logic.
