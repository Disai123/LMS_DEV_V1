Functional Requirements

The functional requirements define the specific actions the Todo App must be able to perform. These are focused on core task management and user interaction.

1 Task Creation

The system must allow users to create new tasks with:

  • A non-empty title text
  • An optional description for detailed information

2 View and Manage Tasks

Users can see their full list of tasks and perform the following:

  • Toggle Completion: Mark tasks as done or active.
  • Delete: Permanently remove a task from the list.
  • Real-time updates: UI should reflect changes immediately.

3 Task Filtering

The application must provide filtering capabilities to focus on specific tasks:

  • All: Show every task in the database.
  • Active: Show only incomplete tasks.
  • Completed: Show only tasks marked as done.
