User Stories

User stories help us understand the application's value from the perspective of our target users.

#1 Adding Daily Tasks

"As a busy professional, I want to quickly add a 'Buy groceries' task so that I don't forget it later."

Acceptance Criteria: Input field focus, enter key submission, task appears instantly at the top.

#2 Tracking Progress

"As a student, I want to check off completed homework assignments so I can feel a sense of achievement."

Acceptance Criteria: Visual feedback on toggle (strikethrough), status persists in the database.

#3 Organizing the View

"As a user with many tasks, I want to filter the list to only see my 'Active' tasks to reduce visual clutter."

Acceptance Criteria: Filter tabs function without reloading the page, animations remain smooth.
