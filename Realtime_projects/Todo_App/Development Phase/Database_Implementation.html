Database Implementation

We use SQLAlchemy as our ORM (Object-Relational Mapper) to interact with SQLite. This allows us to work with Python objects instead of writing raw SQL.

1. Database Connection

The backend establishes a connection to a local todos.db file. SQLite's check_same_thread is disabled because FastAPI handles multiple concurrent threads.

SQLALCHEMY_DATABASE_URL = "sqlite:///./todos.db"
engine = create_engine(SQLALCHEMY_DATABASE_URL, connect_args={"check_same_thread": False})

2. Model Definition

Models are translated into database tables automatically via SQLAlchemy's Base.metadata.create_all(bind=engine) command during startup.

class Todo(Base):
  __tablename__ = "todos"
  id = Column(Integer, primary_key=True, index=True)
  title = Column(String)
  description = Column(String)
  completed = Column(Boolean, default=False)

🛠️ Session Injection

We use a get_db dependency to ensure each API request gets its own database session, which is automatically closed once the request is complete.
