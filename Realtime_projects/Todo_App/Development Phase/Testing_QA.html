Testing & QA during Development

Quality assurance is integrated into the development process. We verify each component and endpoint as they are built.

• Component Verification

Each React component is tested in isolation using Storybook (planned) or simple development pages to ensure props and styles are handled correctly.

• API Documentation (Swagger)

FastAPI automatically generates an interactive documentation page at /docs. This is used to test endpoints manually during development.
