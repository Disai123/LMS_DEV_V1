Frontend Development

The frontend is a modern React application built with Vite for lightning-fast development and optimized production builds. We prioritize smooth animations and state management.

🧠 Local State & Persistence

Tasks are managed using the useState and useEffect hooks. To ensure a seamless user experience, we implement Optimistic Updates: the UI updates the task list immediately when a user clicks 'Complete', while the API call runs in the background.

✨ Framer Motion Integration

We use AnimatePresence for smooth entry and exit of task items. The layout prop is used to animate re-ordering when tasks are filtered or completed, making the interface feel alive.

Code Implementation: Fetching Tasks 

// api.js
export const fetchTasks = async () => {
  const response = await fetch(`${API_BASE}/tasks/`);
  return await response.json();
};

// App.jsx
const [tasks, setTasks] = useState([]);
useEffect(() => {
  fetchTasks().then(data => setTasks(data));
}, []);
