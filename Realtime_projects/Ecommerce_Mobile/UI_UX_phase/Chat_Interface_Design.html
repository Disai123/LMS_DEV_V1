Chat Interface Design

The chat interface is the primary touchpoint between users and the AI agent. This section details the design specifications for all chat UI components, ensuring a cohesive and intuitive user experience.

🔵 Chat Button (Floating)

Specifications
  • Size: 56px × 56px (desktop), 48px × 48px (mobile)
  • Shape: Circular with rounded corners
  • Position: Fixed, bottom-right (24px from edges)
  • Z-index: 9999 (always on top)
  • Background: Blue gradient (#3b82f6 to #2563eb)
  • Icon: MessageCircle icon, white color
  • Shadow: Large shadow for depth
  • Hover: Scale to 1.1, darker blue
States
  • Default: Visible when chat is closed
  • Hidden: Hidden when chat window is open
  • Hover: Slight scale and shadow increase
  • Active: Pressed state with scale down

💬 Chat Window

Layout
  • Dimensions: 400px × 600px (desktop)
  • Position: Fixed, bottom-right
  • Border Radius: 12px (rounded corners)
  • Shadow: Large shadow (2xl)
  • Background: White (#FFFFFF)
  • Structure: Header, Messages, Input
Header
  • Background: Blue (#3b82f6)
  • Text: White, "askunicart" title
  • Actions: Clear chat, Close button
  • Height: 48px
  • Padding: 12px 16px
Messages Area
  • Scrollable: Vertical scroll with auto-scroll
  • Padding: 16px
  • Empty State: Welcome message with icon
  • Spacing: 16px gap between messages
  • Max Height: Flexible (fills available space)
Input Area
  • Text Input: Full width, rounded
  • Send Button: Icon button, right side
  • Placeholder: "Type your message..."
  • Disabled: When loading or empty
  • Padding: 12px 16px

💭 Message Bubbles

User Messages
  • Alignment: Right-aligned
  • Background: Blue (#3b82f6)
  • Text Color: White
  • Border Radius: 12px (rounded)
  • Max Width: 80% of chat width
  • Padding: 12px 16px
  • Font Size: 14px
AI Messages
  • Alignment: Left-aligned
  • Background: Light gray (#f3f4f6)
  • Text Color: Dark gray (#1f2937)
  • Border Radius: 12px (rounded)
  • Max Width: 80% of chat width
  • Padding: 12px 16px
  • Font Size: 14px
  • Line Height: 1.5 (readable)

⏳ Loading & Error States

Loading Indicator
  • Type: Animated spinner (Loader2 icon)
  • Position: Left-aligned (AI message style)
  • Animation: Rotating, smooth
  • Color: Gray (#6b7280)
  • Size: 20px × 20px
Error Messages
  • Style: Red text or border
  • Position: Inline with message or toast
  • Message: User-friendly error text
  • Action: Retry option when applicable
Empty State
  • Icon: Large MessageCircle icon
  • Text: Welcome message
  • Subtext: Example queries
  • Centered: Vertically and horizontally
