Database Design

The data layer provides a stable foundation for agentic reasoning. We use PostgreSQL with SQLAlchemy for relational integrity and LangGraph Checkpoints for state persistence.

Table Primary Keys & Relations Purpose
products id (PK), category_id (FK) Searchable product catalog with tags.
cart_items id (PK), user_id, product_id Proactive cart state for each user.
checkpoints thread_id, checkpoint_id LangGraph binary blob for agent memory.

State Management Strategy

We avoid storing agent reasoning in standard tables. Instead, the entire graph state is snapshotted as a binary checkpoint. This allows the assistant to resume a conversation instantly, even after a system restart or server handover.
