Security Architecture

Security in an agentic system is paramount. We implement a Zero-Trust Agents model, where workers are never given direct access to raw infrastructure without a strict middleman layer.

🛡️

Tool Sandboxing

Every tool call is validated via Pydantic schemas. Agents only provide the arguments, never the execution logic. Programmatic overrides ensure `user_id` cannot be hijacked by the LLM.

🔑

User Context Injection

The system retrieves the authenticated user's ID from the request headers and injects it into the LangGraph `Configurable` state, ensuring cart actions are only performed for the logged-in user.

🔄

Recursion Limits

To prevent infinite agent loops and resource exhaustion, the orchestrator graph implements a hard recursion limit (e.g., 20 steps per turn), returning a fallback error if reached.
