Navigation Flow

The navigation flow in an agentic system differs from traditional apps. It is led by conversational intent, where the assistant dynamically transitions between workers based on user needs.

Entry State (Supervisor)
Search Worker
Cart Worker
Support Worker
Tool Node (Secure Execution)

State Transition Logic

  • Supervisor → Worker: Occurs when the supervisor identifies a specific intent (e.g., "I want to search...").
  • Worker → Tool: Occurs when the worker requires external data or action (e.g., fetching product list).
  • Worker → Supervisor: Occurs after a tool call returns data or if the worker cannot fulfill the request.
