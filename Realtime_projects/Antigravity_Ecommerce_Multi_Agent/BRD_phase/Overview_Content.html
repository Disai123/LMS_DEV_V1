Project Overview

Project Video

This phase writes BRD.md for one multi-agent feature on the existing ShopEasy store. The user talks to one chat. An Orchestrator picks a specialist. Specialists reuse the existing React, FastAPI, and PostgreSQL application. Do not rebuild the store.

Phase Objectives

  • Define the Orchestrator and three specialists: Product Search, Cart, and Order Management
  • Keep Product Search read-only. Cart and Order Management may only use existing allowed actions
  • Reuse existing login, permissions, and the PostgreSQL/Neon database
  • Record in-scope and out-of-scope requests for each agent
  • Set the stack: ReactJS, FastAPI, LangGraph, LangChain, Langfuse

Deliverables

  • Multi-Agent E-Commerce Architecture Blueprint
  • Detailed Functional Requirements for AI Agents
  • Security & Privacy Compliance Framework
  • Agent Persona & Behavioral Definitions
  • Scalability & Performance Targets
