Frontend Development

The frontend is built with React 18 and Vite. It provides a high-fidelity, reactive interface that synchronizes with the agent's internal state.

Conversational SSE Integration

Instead of traditional JSON polling, we use EventSource to stream agent responses. Tokens are rendered instantly, creating a fluid, human-like typing experience.

SSE Message Handler
eventSource.onmessage = (event) => {
    const data = JSON.parse(event.data);
    if (data.type === 'token') {
        setCurrentResponse(prev => prev + data.content);
    }
};

Reactive Component State

The global cart state is automatically updated whenever the agent confirms a successful tool call. This ensures the UI stays "Proactive" without requiring manual page refreshes.
