Database Implementation

The data layer utilizes PostgreSQL via SQLAlchemy. We implement specialized repositories that the agents use for tool execution, ensuring strict user-bound data access.

# Tool Repository Method
async def add_to_cart(user_id: int, product_id: int):
session = await get_db_session()
cart_item = CartItem(
user_id=user_id, # Injected securely from state
product_id=product_id
)
session.add(cart_item)
await session.commit()

The implementation focuses on the LangGraph Persistence Hub, which uses a dedicated PostgreSQL table to store binary snapshots of the agent's memory (checkpoints).

Implementation Highlights

AsyncPG for high-performance non-blocking database operations.
Alembic for managed schema migrations and versioning.
Secure Repository Pattern to isolate database logic from agents.
