Frontend Development

The frontend consists of a React chat component (`AskUnicartChat.tsx`) and a Zustand store for state management. The component provides a floating chat interface accessible from any page.

💬 Chat Component Structure 

// components/AskUnicartChat.tsx

export default function AskUnicartChat() {
  // Zustand store hooks
  const { messages, isLoading, isOpen, sendMessage, setOpen } = useChatStore()
  
  // Local state
  const [input, setInput] = useState('')
  
  // Handlers
  const handleSubmit = async (e) => {
    await sendMessage(input)
    setInput('')
  }
  
  return (
    <>
      {/* Floating chat button */}
      {/* Chat window (when open) */}
      {/* Message list */}
      {/* Input field */}
    </>
  )
}

📦 Zustand Store (store/chat.ts)

State Management
  • messages: Array of message objects
  • isLoading: Boolean for loading state
  • isOpen: Boolean for chat window visibility
  • error: Error message if any
  • conversationId: Current conversation ID
Actions
  • sendMessage: Sends message to API, updates state
  • setOpen: Toggles chat window visibility
  • clearChat: Clears messages and resets state
  • loadConversation: Loads conversation history

🎨 Component Features

Auto-Scroll

Messages area auto-scrolls to bottom when new messages arrive.

Loading States

Shows loading spinner while AI is processing request.

Error Handling

Displays user-friendly error messages for API failures.

Empty State

Shows welcome message when no messages exist.
