Development Overview

Project Video

Development in this project focuses on building a Single AI Agent powered by OpenAI function calling. We build deterministic tool modules first, then wire the backend API route that orchestrates the agent's reasoning loop and tool execution.

Development Steps

1
Tool Module Development
Implementing Catalog Scout, Inventory Sentinel, Recommendation Engine, and Cart Manager.
2
Backend API Route
Next.js API route with JWT auth, conversation history, and OpenAI function calling loop.
3
Reactive UI Widget
React chat component with Zustand state management for floating chat interface.

Quality Standards

  • ✅ JWT-validated authentication on every request
  • ✅ Tool execution sandboxed per user_id
  • ✅ Response time target < 2 seconds end-to-end
  • ✅ Full TypeScript type safety throughout
