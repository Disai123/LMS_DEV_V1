Design System

A comprehensive design system ensures consistency and efficiency across the chat interface and AI agent components. This design system is specifically tailored for conversational UI elements.

🎨 Color Palette

Primary Blue

#3B82F6

Chat button, user messages, active states

AI Message

#F3F4F6

AI assistant message bubbles

Success

#10B981

Success confirmations, positive actions

Error

#EF4444

Error messages and warnings

Background

#FFFFFF

Chat window background

Text

#374151

Primary text color

📝 Typography

Font Family
Inter - Primary font for chat interface
Poppins - Headings and emphasis
Font Sizes
Message Text: 0.875rem (14px) - Readable chat messages
Input Field: 1rem (16px) - Comfortable typing size
Header: 1.125rem (18px) - Chat window header

🧩 Chat Components

Chat Button
  • Fixed position (bottom-right)
  • Circular, 56px × 56px
  • Blue gradient background
  • Message icon
Message Bubbles
  • User: Blue background, right-aligned
  • AI: Gray background, left-aligned
  • Rounded corners (8px)
  • Max width: 80% of chat width
Input Field
  • Text input with placeholder
  • Send button (icon)
  • Disabled state when loading
  • Auto-focus on open
Loading Indicator
  • Animated spinner
  • Shown during AI processing
  • Left-aligned (AI message style)
  • Pulsing animation

📱 Responsive Design

Desktop (≥ 768px)
  • Chat window: 400px × 600px
  • Fixed position bottom-right
  • Full chat interface visible
Mobile (< 768px)
  • Chat window: Full screen or 90% width
  • Optimized touch targets (min 44px)
  • Keyboard-aware positioning
  • Larger text for readability
