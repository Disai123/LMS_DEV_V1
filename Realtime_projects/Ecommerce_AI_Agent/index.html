Project Overview

This Ecommerce AI Agent project focuses exclusively on implementing the askunicart AI assistant for e-commerce platforms. It demonstrates how to build an intelligent shopping assistant that helps customers browse products, check stock, get recommendations, and manage their cart through natural language conversations. The project is structured into six distinct phases, covering everything from requirements gathering to production deployment.

💬
Natural Language Chat
Conversational AI interface for product search and queries
🔍
Product Search
Intelligent product discovery via natural language
📦
Stock Checking
Real-time inventory availability queries
🛒
Cart Management
Add, update, and remove items via chat
🎯
Recommendations
AI-powered product suggestions
🧠
OpenAI Integration
GPT-4o-mini with function calling
