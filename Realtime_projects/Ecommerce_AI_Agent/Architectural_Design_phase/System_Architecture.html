System Architecture

The system architecture for askunicart follows a layered approach, separating concerns between frontend, API, AI integration, and data layers. This ensures scalability, maintainability, and security.

🏗️ High-Level Architecture

┌─────────────────────────────────────────┐
│ Frontend Layer (React/Next.js) │
│ • AskUnicartChat Component │
│ • Zustand Store (chat state) │
└─────────────────────────────────────────┘
↓ HTTP Request
┌─────────────────────────────────────────┐
│ API Layer (Next.js API Routes) │
│ • POST /api/askunicart │
│ • GET /api/askunicart │
│ • Authentication Middleware │
└─────────────────────────────────────────┘
↓ OpenAI SDK
┌─────────────────────────────────────────┐
│ AI Integration (OpenAI) │
│ • GPT-4o-mini Model │
│ • Function Calling │
│ • Context Management │
└─────────────────────────────────────────┘
↓ Tool Calls
┌─────────────────────────────────────────┐
│ Tool Modules (lib/askunicart) │
│ • Catalog Scout │
│ • Inventory Sentinel │
│ • Recommendation Engine │
│ • Cart Manager │
└─────────────────────────────────────────┘
↓ Database Queries
┌─────────────────────────────────────────┐
│ Database (PostgreSQL + Prisma) │
│ • Conversation & Message Tables │
│ • Product, Cart, User Tables │
└─────────────────────────────────────────┘

🔄 Request Flow

1
User sends message
Chat component sends POST request to /api/askunicart
↓
2
API validates & authenticates
JWT token verified, user ID extracted
↓
3
Load conversation history
Retrieve last 20 messages from database
↓
4
Call OpenAI API
Send message with context and available tools
↓
5
Execute tool calls
AI requests tool execution (e.g., searchProducts)
↓
6
Query database
Tool modules query PostgreSQL via Prisma
↓
7
AI generates response
OpenAI creates natural language response from tool results
↓
8
Save & return response
Messages saved to database, response sent to frontend

🧩 Component Responsibilities

Frontend (React)
  • Render chat UI
  • Handle user input
  • Display messages
  • Manage local state
API Route
  • Authenticate requests
  • Manage conversations
  • Integrate with OpenAI
  • Handle tool execution
Tool Modules
  • Product search
  • Stock checking
  • Cart operations
  • Recommendations
Database
  • Store conversations
  • Store messages
  • Product data
  • Cart data
