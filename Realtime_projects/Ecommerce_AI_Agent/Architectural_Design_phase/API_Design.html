API Design

The API design defines RESTful endpoints for the AI agent, handling message sending, conversation retrieval, and AI interactions. All endpoints require authentication via JWT tokens.

📤 POST /api/askunicart

Description

Send a message to the AI assistant and receive a response. Creates or updates conversation as needed.

Request
POST /api/askunicart
Headers:
  Authorization: Bearer <JWT_TOKEN>
  Content-Type: application/json

Body:
{
  "message": "Show me laptops",
  "conversationId": "optional-conversation-id"
}
Response
{
  "success": true,
  "message": "Here are some laptops...",
  "conversationId": "conv_123",
  "toolCalls": [] // Optional: if tools were used
}

📥 GET /api/askunicart

Description

Retrieve conversation history. Can get all conversations for a user or a specific conversation.

Request
GET /api/askunicart?conversationId=conv_123
Headers:
  Authorization: Bearer <JWT_TOKEN>
Response
{
  "success": true,
  "conversation": {
    "id": "conv_123",
    "title": "Product Search",
    "messages": [
      {
        "id": "msg_1",
        "role": "user",
        "content": "Show me laptops",
        "createdAt": "2025-01-20T10:00:00Z"
      },
      {
        "id": "msg_2",
        "role": "assistant",
        "content": "Here are some laptops...",
        "createdAt": "2025-01-20T10:00:01Z"
      }
    ]
  }
}

🔒 Authentication

JWT Token Required

All endpoints require a valid JWT token in the Authorization header. Token is validated via middleware before processing requests.

User Isolation

User ID is extracted from JWT token. All conversations and messages are isolated per user to ensure privacy.

Error Responses

401 Unauthorized: Invalid or missing token

400 Bad Request: Invalid request body

500 Internal Server Error: Server or AI API error

⚡ Performance Considerations

Context Limiting

Only last 20 messages loaded for context to optimize token usage and response time.

Timeout Handling

API route configured with 60-second timeout for AI requests (maxDuration).

Error Handling

Graceful error handling with user-friendly messages for API failures.
