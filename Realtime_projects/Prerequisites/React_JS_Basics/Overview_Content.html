🎬 React JS Basics — Full Introduction Lecture

React.js is a declarative, component-based JavaScript library developed by Meta for building fast and interactive user interfaces. It uses a virtual DOM (Document Object Model) to efficiently update and render just the right components when your data changes. React is the UI engine behind every frontend project in this curriculum.

🎯 What You'll Learn

  • React fundamentals: components, JSX, and the virtual DOM
  • State management with useState and useReducer
  • Side effects and data fetching with useEffect
  • Component composition, props, and lifting state up
  • Working with React Router for single-page app navigation
  • Using Vite as the modern build toolchain for React projects

📦 Tech Stack Context

  • React 18+ with functional components (no class components)
  • Vite for fast development server and HMR (Hot Module Replacement)
  • Axios / Fetch API for communicating with FastAPI backends
  • CSS Modules or plain CSS for styling (no mandatory CSS framework)
